# IM MONSTER 本周任务：现有场景中的开场片段

周期：2026-10-28 至 2026-11-03；所有时间为北京时间。任务由管理者本轮要求派发，工时是适合一周兼职投入的估算，不代表已完成工作。正式采用和剧情定稿仍由管理者决定。

## 本周结果

以现有图书馆和圆形厅制作一段可从头走通的 6–8 分钟剧情候选：**伊莱恩整理遗赠档案 → 警报与受袭 → 提取记忆未封存、黑屏 → 身份未明的睁眼 → 前往下层维护厅稳定供能 → 返回档案馆取回记录。**

时长是制作目标，必须实测记录；不靠拉长字幕或等待凑时长。本周交付候选，不要求完成全部世界观、最终决战、亡灵大军或完整监狱。

## 故事与场景如何衔接

以下空间解释和任务桥段是本轮制作方案，可调整，不冒充已定稿设定。

| 已有内容 | 本轮剧情用途 | 如何发生 |
| --- | --- | --- |
| 哥特图书馆、书架、工作桌、展台 | 终境守藏院的记忆档案馆工作区 | 玩家作为封忆师整理三份遗赠记录，通过短文本及物件操作认识岗位和百年前战争 |
| 已有书籍预览交互 | 档案查验原型 | 使用三份新剧情数据，不把旧演示馆藏当成已经实现的剧情任务系统 |
| 馆内已有自动门及一处侧门 | 通往下层维护厅的入口 | 侧门标识、短过渡、加载/淡出切换；首版允许区域传送，镜头和任务必须给出空间方向，不能靠暂停菜单进入故事 |
| 圆形封印厅候选 | 下层封印维护厅，负责导流与供能巡检 | 玩家在三个明确标记的维护节点稳定局部回路，保护上方尚未转移的记忆。它不是源石本体所在的最深封印室 |
| 回到同一图书馆 | 返回死亡现场的铺垫 | 本周止于“取回记录”目标；空间保持可辨认，为后续遗体反转复用同一工作区 |
| 已有 Boss、禁页、裂地、冲撞 | 独立战斗技术验证资源 | 调试入口保留；不接在典狱长救人之后作为当前故事的必经敌对战。最终战何时发生、击败结果和人物解释仍待后续剧情决定 |

本周通过声音、字幕、少量灯光和道具状态表现袭击；不新增完整教派战斗队伍和 NPC 行走系统。典狱长以近处画外声音及局部施法表现救助，角色表演有占位时必须标明。

### 已确认、必须保留的剧情规则

- 玩家开场扮演封忆师伊莱恩·维尔；其死亡记忆被人形怪物拾取，黑屏到睁眼保持第一人称连续感。
- 醒来后，任务、字幕、UI、物件标签与系统提示都不得确认玩家仍是伊莱恩，也不得直接确认怪物身份。
- 典狱长救的是眼前的幸存者。不要称呼其为伊莱恩，不说“我把你复活了”；先让玩家见到其救援、疏散及维持供能的行动。
- 后续第一次揭示只确认“我不是伊莱恩”：开场亲手系的蓝色封档绳、工作牌和腹部伤口在遗体上构成三条证据；人形怪物身份在更后面揭示。
- 主角身份恢复、源石大招、狂暴与最终决战属于后续大纲。本周不补写结局，不把典狱长简单写成邪恶反派。
- 亡灵携带自身记忆；档案馆保存自愿交出的遗赠。普通档案整理不等于随意吸取亡灵记忆或授予任意能力。

## 最小流程与三个交接点

下列标识是本轮建议约定，尚不存在于当前源码中。程序成员可调整实现形式，但变更前需与另两位同步。

| 顺序 | 事件标识 | 内容与完成条件 |
| --- | --- | --- |
| 1 | `STORY_ARCHIVE_START` | 工作牌显示伊莱恩姓名；完成蓝绳动作/交互替代表现；查验三份档案 |
| 2 | `STORY_BREACH` | 警报中止工作，限定小范围受袭表现；腹部受伤及记忆落地声；一次黑屏过渡 |
| 3 | `STORY_AWAKEN` | 同一视角睁眼、画外救助、恢复操作；不显示姓名和身份判断 |
| 4 | `STORY_MAINTENANCE_ENTER` | 从馆内侧门进入下层厅，在三个维护节点依次完成交互；不生成敌对典狱长 |
| 5 | `STORY_ARCHIVE_RETURN` | 维护结束，回到可辨认的工作区；目标改为取回记录；本周候选结束 |

场景交接：以程序工程 `1.0.6/` 为唯一运行工程，Unity **6000.3.25f1**、URP **17.3.0**。圆厅本地原点 `(0,0,0)`、地面 `Y=0`、活动半径 `14m`。中央活动区不加台阶或大型障碍；剧情装置放在可绕行位置。现有战斗技术仍在 `(160,0,0)` 实例化；故事与战斗使用同一美术资源的独立实例/模式，不得同时堆叠在同一点。

程序拥有运行逻辑、场地装配与最终场景接线；场景成员拥有 `Assets/Art/SealChamberStudy/` 及新剧情道具；剧情成员拥有 `团队任务/剧情/` 下的文本、事件和演出表。共享 `.unity` 和场地 Prefab 由程序成员统一装配，另两位先交可引用资产和表格，不同时覆盖同一文件。

## 共同验收

1. 从游戏正常入口开始，顺序完成五个事件；旧暂停菜单中的“深入探索”不能代替故事路线。
2. 每个关键交互具有一次性完成条件，重复点击、过渡时按键、打开菜单不会跳过必要节点或锁死输入。
3. 进入/返回后玩家落地、相机和输入正常；一次返回及至少三次往返无重复场地、HUD、任务回调和临时特效。
4. 空中暂停/继续、隔墙吞印、近墙射击各有针对性复现和修复结果；既有36项技能检查继续通过。旧检查通过不能代替新场景/新流程测试。
5. 贴墙、贴柱、冲刺、跳落、蹲起、重试与返回经过真实控制器验证；没有新旧地面叠加或可见墙裙穿入。
6. 故事模式醒来后无“怪物力量”“收容物编号零”“它认出了你”等提前泄露身份的面向玩家文案；剧情成员提供替代文本，程序负责接入。旧战斗调试入口明确标识“非剧情技术测试”，不接入开场路线、不参与本周故事展示；本周不要求重写其完整剧情。
7. 提交测试设备、平台、分辨率、画质、候选片段时长与战斗高峰性能记录。未达到或未测试就如实记录，不把批处理帧率认定为目标设备达标。
8. 成员只推个人分支。管理者按任务收取到 `codex/team-submit`；本轮技术验收与任务派发不等于进入正式 `main`。
