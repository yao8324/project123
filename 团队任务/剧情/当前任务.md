## 工作包

1. **五个事件的分场脚本，5h。** 按“工作→受袭→睁眼→维护→返回”写玩家做什么、看到什么、听到什么、何时归还操作权。每场注明现有场景点位、所需新资产、进入与完成条件，不堆叙述旁白。暂定6–8分钟，交程序实测调整。
2. **三份档案与短字幕，4h。** 三份档案各120–180中文字、每份提炼一个核心信息：百年前战事记录、自愿遗赠规则、维护供能为何保护记忆。字幕单条建议不超过两行；救助台词不叫醒来后的玩家“伊莱恩”，不确认复活或怪物身份。具体台词是待管理者审阅候选。
3. **事件接入表，4h。** 交CSV或JSON以及人可读分场表，逐条含 `event_id / scene_anchor / prerequisite / trigger / interaction / text / audio_cue / completion / repeat_policy`。状态标识按总计划五个事件；标明必播、可跳过和一次性，避免字幕重复或错序。程序未提供接口时先交静态表，不擅自改运行脚本。
4. **反转与身份泄露复核，3h。** 给后续“返回档案室认出遗体”做6–8格文字分镜，复用本周同一工作区、蓝绳/牌/伤口三证据。本周不要求把整场做进游戏。列旧HUD/结算/任务文字的替换建议，第一反转只到“我不是伊莱恩”；更后面的怪物身份和最终战不提前定稿。
5. **联合走查与整理，2h。** 用程序候选实走/观看完整录屏，核对节奏、信息顺序、身份泄露及典狱长正面形象，提交具体问题点和修改版本。
