# 更新日志

## 1.0.5 · 开发中（整理日期：2026-10-15）

基于 1.0.4 / c3a80b9；开发分支 dev/1.0.5。本条记录当前工作区变化，不表示已创建 Release、标签或完成推送。

### 新增

- 统一 Esc 菜单与棕金风格 UI：探索指南、设置、用户馆藏空状态、功能概述。
- 可操作的画质按钮、鼠标灵敏度滑条、按键换绑及 JSON 保存。
- 魔法书、魔法阵和底座的连续交互区域与提示容差。
- “深入探索”金紫装饰按钮与未来 Boss 战说明页，仅作为界面入口。
- 宽幅自动魔法大门、双面封印装饰、接近开门/远离关门及通行保护。

### 调整与修复

- 默认高画质；均衡模式仍可通过 F8 或设置选择。
- 中文 TMP 字体与界面排版、横线分隔、悬停反馈及恢复默认按钮。
- 馆藏明确为用户导入文件集合，不再把演示书籍计入用户馆藏。
- 地毯与地面重叠闪烁；魔法展示位置、漂浮与翻页节奏。
- 入口装饰、门上方封口、中央入口拓宽与相应碰撞结构。
- 补齐 LFS 实体，并更新版本 README、架构、协作与上传准备说明。

### 尚未交付

真实文件导入、KnowledgeBook 数据库、归档生成、检索、阅读服务、AI/RAG、多人及 Boss 战。当前功能验证边界和已知问题见 [README](README.md)。
