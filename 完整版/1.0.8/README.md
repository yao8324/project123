# IM MONSTER：遗赠 1.0.8

从书页进入缚魂者、缄默典狱长和黄金翼圣骑士三场战斗，跟随关前和战后对白走到撤离结尾。支持连续挑战、单独选关和本关重试。

## 下载与启动

[Windows x64 完整游戏 ZIP](IMMonster_1.0.8_Windows.zip)

在文件页点击 **Download**，完整解压后运行 `IMMonster_ThreeBoss_Windows/IMMonster.exe`。请将 `IMMonster_Data`、`MonoBleedingEdge` 和 DLL 与程序保留在同一目录。

## 操作

WASD 移动，鼠标观察，空格跳跃，Shift 冲刺，左键连斩，右键举盾或弹反，数字键 1–4 使用技能，I 查看装备，Esc 暂停。
