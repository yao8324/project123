# IM MONSTER 1.0.9 · 三 Boss 完整版

下载 [Windows 完整游戏 ZIP](IMMonster_1.0.9_Windows.zip)，完整解压后运行 `IMMonster_1.0.9_Windows/IMMonster.exe`。exe、UnityPlayer.dll 和 Data 目录必须放在一起。

## 本轮更新

- 第一章换为精细大厅与五类小怪同时召唤的完整战斗。
- Boss 追加三发扇形魂弹，带预警、锁向和吞印/格挡应对。
- 召唤引导仅 2.4 秒，需造成 180 实际伤害打断；锚点生命提高至 240。
- 击败 Boss 后到北侧控制台按 E，选择收容/契约，再点“完成第一章·继续故事”，接典狱长、圣骑士与最终结局。
- 书本支持连续三关和单关挑战，失败可重试，暂停可返回书本。

## 操作

WASD 移动、鼠标转向、Shift 冲刺、Esc 暂停。第一章左键秘文弹、右键吞印/格挡、E 交互；后两关按原剑盾与技能提示操作。

## 验证与版本

244 项 Unity Play Mode 整合检查通过；包括实际射线/近战命中、死亡重试、战后衔接和结局。Windows 构建成功，0 错误、18 条平台不支持光追着色器编译的警告；构建结果与 ZIP 校验见同目录报告。Windows 实机、真人难度及长时间性能尚未复验。人物动作仍以现有程序驱动表现为主。
