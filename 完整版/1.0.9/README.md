# IM MONSTER：遗赠 1.0.9

翻开故事书，从缚魂者的亡灵大厅出发，挑战典狱长和黄金翼圣骑士，完成撤离故事。可连续挑战或单独选关，失败后可重试本关。

缚魂者会召唤五类亡灵并释放扇形魂弹。玩家可打断召唤、关闭锚点，并在击败 Boss 后到北侧控制台选择收容或契约。

## 下载与启动

[Windows x64 完整游戏 ZIP](IMMonster_1.0.9_Windows.zip)

在文件页点击 **Download**，完整解压后运行 `IMMonster_1.0.9_Windows/IMMonster.exe`。请将 `IMMonster_Data`、`MonoBleedingEdge` 和 DLL 与程序保留在同一目录。

## 操作

WASD 移动，鼠标观察，Shift 冲刺，Esc 暂停。第一关左键发射秘文弹、右键吞印或格挡、E 交互。后两关使用剑盾与数字键技能，具体操作见游戏内提示。
