# IM MONSTER：遗赠 · 完整版 1.0.10

灾变后的魔法图书馆里，撤离尚未结束。你将翻开故事书，从亡灵大厅出发，突破典狱长的封印，面对仍在守门的黄金翼圣骑士。

## 下载与启动

[Windows x64 完整游戏 ZIP](IMMonster_Windows.zip)

打开文件页点击 **Download**。完整解压后运行 `IMMonster/IMMonster.exe`。请将 `IMMonster_Data`、`MonoBleedingEdge`、`UnityPlayer.dll` 等文件保留在程序旁，不能只复制 EXE。无需安装 Unity。

## 三章挑战

- **缚魂者**：五类亡灵同时登场，躲避扇形魂弹、打断召唤、关闭锚点；击败后到北侧控制台选择收容或契约，继续下一章。
- **缄默典狱长**：观察封印预警，在闪避、格挡、吞印与反击之间寻找机会。
- **黄金翼圣骑士**：象牙盔甲与黄金羽翼，长距离突刺、三枚审判光矛、展翼跳劈、折光瞬斩和召唤法阵；在宽阔圣堂中争取撤离时间。

在书页选择“翻开故事 · 连续挑战三关”，或单独选择章节。胜利后继续战后剧情，完成下一关；失败可重试本关。

## 操作

WASD 移动，鼠标观察，Shift 冲刺或突进，Esc 暂停。

第一关：左键发射秘文弹，右键吞印或格挡，E 与控制台交互。

后两关：左键连斩，右键举盾或弹反，空格跳跃，数字键 1–4 使用技能，I 查看装备。游戏内可查看按键说明。
