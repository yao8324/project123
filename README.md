## 打开工程

```bash
git lfs install
git clone https://github.com/yao8324/project123.git
cd project123
git lfs pull
```

在Unity Hub添加仓库内的 **`1.0.6/`**，使用 **Unity 6000.3.25f1**。项目采用 **URP 17.3.0**，等待Packages解析和资源导入完成。

打开 `Assets/Scenes/MilanLibrary_Magic_V6.unity`，进入Play Mode。图书馆为现有漫游/交互原型；Esc菜单中的“深入探索”进入现有Boss技术演示，使用本次接入的圆形厅。该入口不是已完成的新剧情开场。
