# IM MONSTER · 团队协作入口

本仓库由管理者统一派任务、收成果和验收。

- [简单协作说明](协作说明.md)：每个人先看这一份。
- [任务总览](团队任务/README.md)：查看三个人的任务入口。
- [程序成员任务](团队任务/程序/当前任务.md) · [场景成员任务](团队任务/场景/当前任务.md) · [剧情成员任务](团队任务/剧情/当前任务.md)

| 分支 | 用途 |
| --- | --- |
| `main` | 管理者确认采用的正式内容 |
| `codex/team-submit` | 管理者集中收取、检查和整合成果 |
| `program` | 程序成员开发与自主尝试 |
| `art` | 场景成员开发与自主尝试 |
| `planner` | 剧情成员开发与自主尝试 |

三位成员暂按职责代称，实际姓名由管理者填写。当前建立的是协作结构；任务尚待管理者派发，Unity 游戏工程尚未导入这些协作分支。
