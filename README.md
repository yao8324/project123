# IM MONSTER：遗赠

翻开魔法图书馆中的故事书，依次挑战缚魂者、缄默典狱长和黄金翼圣骑士，在封印与撤离之间完成三章故事。

## 当前完整版

**1.0.10** · [下载 Windows 完整游戏与查看介绍](完整版/当前完整版/README.md)

缚魂者拥有五类亡灵召唤与扇形魂弹，击败后可在控制台处理灵魂并继续下一章。圣骑士采用黄金羽翼与象牙盔甲，拥有长距离追击、三枚光矛、跳劈、瞬斩及各自的蓄力法阵。

支持连续三关、单独选关、失败重试、战后剧情与结尾。游戏无需安装 Unity。
