# Arcane Archive P0 实施路线图

## 1 第一人称与交互

**交付物：** 第一人称相机、移动与视角控制、射线目标检测、E 键交互提示、`IInteractable` 交互约定，以及 UI 打开时的输入和鼠标切换。

**验收方法：** 在 `LibraryMain` 中可以 WASD 移动、鼠标转向、Shift 加速；准星指向可交互测试物时显示提示，按 E 可触发交互；打开和关闭测试 UI 后，玩家输入和鼠标状态正确切换。

## 2 灰盒图书馆

**交付物：** 基于 `LibraryMain` 的中央大厅、上传区、检索台和书架区灰盒布局，以及可通行地面、碰撞和基础灯光。

**验收方法：** 玩家可无卡死地从出生点走到上传区、检索台和各书架区；场景在 URP 3D Renderer 下无材质或灯光错误。

## 3 数据驱动书架

**交付物：** `KnowledgeBook`、`LibraryDatabase`、`ShelfDefinition`、`BookShelf`、`BookView` 的数据关系；类别分配、空槽分配和书籍视觉呈现。

**验收方法：** 通过测试数据创建多条书籍记录后，书籍按类别出现于正确书架和槽位；重建 BookView 后数据不丢失；场景物体不包含硬编码书名、关键词、文件路径或槽位事实。

## 4 文件导入

**交付物：** UploadStation、文件选择、复制到 `Application.persistentDataPath`、JSON 元数据保存，以及文件转书籍与书架归档。

**验收方法：** 导入 TXT、Markdown、图片、PDF、Word、PPT 六类样例后，源文件不写入 Assets，持久化目录有副本，JSON 有对应记录，场景中生成归档书籍。

## 5 阅读

**交付物：** ReadingPanel、书籍信息显示、TXT/Markdown 内容阅读、图片预览与 PDF/Word/PPT 的系统默认程序打开。

**验收方法：** 从场景书籍打开信息面板；TXT 和 Markdown 可读，图片可预览，PDF、Word、PPT 可打开原文件；关闭面板后恢复玩家输入与鼠标锁定。

## 6 检索

**交付物：** SearchStation、标题/原始文件名/关键词的不区分大小写模糊搜索、结果列表、书籍和书架高亮、无结果状态。

**验收方法：** 用大小写不同、标题片段、原始文件名片段和关键词均可找到预期书籍；多结果和无结果状态正确；新搜索会清除旧高亮。

## 7 魔法表现

**交付物：** P1 范围内的魔法阵、书籍飞行、水晶球、粒子、分类书架、UI 动画、环境音乐和蜡烛火焰。

**验收方法：** 所有效果可被独立启用或关闭；上传和搜索流程的视觉反馈清晰，且在目标设备上不影响 P0 闭环稳定运行。

## 8 构建答辩

**交付物：** 可执行构建、演示数据、操作说明、答辩演示脚本和风险备选方案。

**验收方法：** 干净启动后，从“进入大厅 → 上传资料 → 资料生成魔法书 → 书籍归档至书架 → 检索台搜索 → 目标书籍高亮 → 打开查看”连续完成一次；Console Error 为 0，且 Build Settings 仅使用 `LibraryMain.unity` 作为启动场景。
