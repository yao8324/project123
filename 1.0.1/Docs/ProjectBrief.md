# 虚拟环境设计 项目简报

**产品名称：** Arcane Archive 魔法图书馆  
**项目定位：** 第一人称沉浸式魔法图书馆个人知识库。用户进入魔法图书馆，将个人资料导入为馆内的魔法书籍，并通过探索、书籍交互与检索查找和查看资料。

## 产品目标

以“导入知识、收藏知识、寻找知识、阅读知识、返回探索”为核心循环，在一个可探索的魔法图书馆中完成资料归档与检索。中央大厅承担出生点、氛围建立和区域交通功能；书架区承担知识存储；检索台承担标题和关键词搜索；上传区承担资料导入与书籍生成。

## P0 最小可交付版本

P0 必须形成可运行的完整演示，包含：

- 第一人称移动、鼠标视角和 Shift 加速。
- 可探索的魔法图书馆大厅及书架。
- 文件导入。
- 文件转书籍：每个导入文件生成一条书籍记录，并映射为场景中的书籍。
- 书籍信息面板。
- 标题和关键词检索。
- 目标书籍与所属书架高亮。

完整演示闭环为：

> 进入大厅 → 上传资料 → 资料生成魔法书 → 书籍归档至书架 → 检索台搜索 → 目标书籍高亮 → 打开查看。

## 文件格式策略

| 文件格式 | P0 行为 |
| --- | --- |
| TXT、Markdown | 在 Unity 阅读面板中显示文本内容。 |
| 图片 | 在 Unity 内预览。 |
| PDF、Word、PPT | 导入文件元数据，并调用操作系统默认程序打开原文件。 |

P0 不承诺解析或在 Unity 内呈现 Office、PDF 的正文内容；这些文件只需完成导入、元数据展示、书籍映射与外部打开。

## P0 验收标准

1. 启动后，用户可以使用 WASD 移动、鼠标控制视角，并使用 Shift 加速，在大厅和书架区域自由行走。
2. 用户可以导入至少 TXT、Markdown、图片、PDF、Word、PPT 六类示例文件；每个成功导入的文件都有名称、类型、导入时间等可查看元数据。
3. 导入文件会生成对应的魔法书，并归档到可见书架；书籍信息面板能显示其元数据。
4. 用户可在检索台以标题或关键词搜索已导入资料；匹配结果会高亮目标书籍及所属书架。
5. TXT 和 Markdown 能在 Unity 阅读面板中阅读，图片能在 Unity 内预览；PDF、Word、PPT 能通过系统默认程序打开。
6. 可按“完整演示闭环”从进入大厅到打开目标资料连续完成一次，无阻断性错误。

## P0 非目标

- 不实现 AI 猫头鹰、RAG 或模糊语义问答。
- 不实现多人、账号、NPC、公共/私有图书馆、知识关系可视化。
- 不实现多房间、多楼层或大型开放世界内容。
- 不在 Unity 内解析 PDF、Word、PPT 的正文、排版或幻灯片内容。
- 不要求复杂的书籍飞行、魔法阵、水晶球、粒子、UI 动画或环境音乐。

## 初始工程基线

当前工程为 Unity 6.3.24f1 的 Universal 2D 模板，已安装 URP 17.3.0 与 Input System 1.20.0。输入资产已具备 Move、Look、Sprint、Interact 等动作绑定，但项目当前只有正交相机、Global Light 2D 和 2D Renderer，尚无业务脚本、3D 模型、Prefab 或业务场景内容。

正式进入场景开发前，应以保留现有工程和输入资产为前提，建立使用 Universal Renderer 的 3D URP 配置及独立 3D 测试场景；该迁移不属于本简报定义的 P0 功能实现。
