# 1.0.1 版本说明

这是 `lixiang` 分支的首个完整归档版本。工程源自 GitHub 提交 [`a276850`](https://github.com/yao8324/project123/commit/a2768501da05a6f91c87cd9b17922be7556b9010)，原提交中的 Unity 工程位于分支根目录。本次归档将其移入 `1.0.1/`，保留原有项目文件和本说明中的更新记录；未加入其他本地工作区的未提交改动。

## 工程概况

- Unity 版本：`6000.3.24f1`；使用 Unity Hub 打开当前 `1.0.1/` 文件夹。
- 工程目录：`Assets/` 保存场景、脚本和资源，`Packages/` 保存包配置，`ProjectSettings/` 保存项目设置，`Docs/` 保存设计与验证文档。
- 启动场景：`Assets/Scenes/LibraryMain.unity`。
- 当前已实现图书馆场景、第一人称控制和基础交互；资料导入、书架数据、检索与阅读闭环仍在规划中。
- 本版本从初始 P0 工程提交 `b53b051` 发展而来；下面保留原 `1.0.1` 更新说明。

## 本次修改

### 玩家移动

- 左 Shift 冲刺改为基础移动速度的倍率计算，默认倍率为 1.5。
- 可在 `Player > First Person Controller > Movement > Sprint Multiplier` 中调整冲刺倍率。

### 跳跃与落地

- 落地检测不再要求物体必须挂载 `GroundSurface`。
- 玩家脚下命中正常、非 Trigger 的碰撞体时即可恢复跳跃，因此落到桌面后可以再次跳跃。
- 可通过 `Ground Layers` 控制哪些碰撞层可以作为地面。

### 蹲下

- 按住 C 平滑蹲下，松开 C 站起。
- 蹲下时同步降低 CharacterController 和玩家镜头。
- 头顶存在障碍时不会强行站起，避免穿模。
- 可在 `Player > First Person Controller > Crouch` 中调整蹲下高度、过渡速度和顶棚检测层。

### 输入绑定

- 鼠标滚轮向上：`Previous`。
- 鼠标滚轮向下：`Next`。
- `Previous` 和 `Next` 当前只完成输入绑定，尚未连接具体业务功能。

## 验证建议

1. 在 `LibraryMain` 场景运行游戏。
2. 测试地面起跳、落到桌面后再次起跳。
3. 按住左 Shift，确认移动速度变为普通速度的 1.5 倍。
4. 按住并松开 C，确认玩家可以平滑蹲下和站起。
5. 在桌子或低矮障碍下松开 C，确认空间不足时保持蹲姿。
6. 滚动鼠标滚轮，确认 Input System 能分别触发 `Previous` 和 `Next`。
