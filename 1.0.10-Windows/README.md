# 《IM MONSTER：遗赠》Windows 试玩版

1.0.10 · 2026 年 11 月 12 日 · Windows x64

## 下载和启动

1. 打开 [IMMonster_Windows.zip](IMMonster_Windows.zip)，选择 **Download** 下载完整压缩包。
2. 解压整个压缩包，双击解压目录中的 `IMMonster.exe`。启动所需的 `IMMonster_Data`、`MonoBleedingEdge` 和 DLL 已随包提供。
3. 在游戏书页选择「翻开故事 · 连续挑战三关」，或单独选择章节。无需安装 Unity。

## 本版改动

- 第一章与后两章使用同一套剑盾操作和界面。左键连斩，右键格挡、弹反或吞印，数字键 1–4 使用技能，Shift 突进，I 查看装备。
- 第三章圣骑士模型和受击判定按原尺寸的 2 倍显示。移动碰撞、技能伤害范围和危险提示沿用原配置。
- 连续剧情包含伊莱恩序章、缚魂官战后回馆、魔法阵上传与书架封藏、典狱长揭晓身份和圣堂撤离。 剧情衔接改为可逐格阅读的漫画，中文旁白与对白显示在插画下方。

完整梗概和各章剧情见 [游戏剧情说明](剧情说明.md)。终章剧透可折叠。
