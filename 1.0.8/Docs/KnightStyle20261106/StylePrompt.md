# 本轮实际执行的骑士风格提示词

阅读最新 1.0.8 的六招、一次五发弹幕、三次追踪落雷、跳劈雷波和 Boss 提示开关，并结合 IM MONSTER 的灾后守藏院故事继续制作。将封印圣骑士塑造为庄严、克制、疲惫的最后守誓者：银灰钢甲为主体，象牙封缄布与暗色关节承托，旧金仅用于结构与权限纹样。用断环与垂直封缄统一面甲、胸甲、护胫、长柄武器及封印门；加强真实甲片层次、护甲中脊和细窄刻线，保留辨识清楚的长柄刃与权限环轮廓。

把终扉前庭完善为可战斗的哥特式封印设施：补齐有厚度的高拱穹面、少量深色嵌窗、低亮度的地面石材拼缝与铜嵌线；北侧封印门为视觉中心，外围未撤走的转运箱与封缄蓝绳暗示救援未完成。地面与建筑纹样保持稳定、低亮度，攻击预警具有更高的明度。强化冷色石材、银甲和暖金技能之间的层次，维持当前三盏实时灯与清楚的通行范围。

本轮专注角色、场地与光照统一，沿用最新六招、数值、输入、碰撞、剧情阈值与提示偏好，不制作召唤组内容或新增结局。采用项目已有纹理和可编辑网格，保留骨骼、双层 LOD、握柄和脚底约束，动态表现共用战斗时钟。交付实际 Unity 资源、同机位前后截图、六招实景检查、暂停/阶段/退出回归和可试玩的 Windows 包；明确剩余手工美术与真人测试边界。

## 项目风格判断

main 比赛策划 v0.3 的美术段落明确使用深色木作、红褐皮革、旧黄铜、暖纸和绿色灯罩；魔法以暖金档案、青蓝/青绿供能、少量深蓝黑共鸣区分。实际图书馆截图也保留尖拱、浅石柱、彩窗、木作与铜边。本轮沿这套哥特设施的材质和符号语言进入更冷的深层封印区，用银灰甲、旧金嵌线、暖色转运箱和蓝色封缄把骑士关接回同一世界。
