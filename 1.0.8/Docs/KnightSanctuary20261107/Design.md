# 终扉圣堂 · 已选概念实施规格
用户授权：在 Unity 根据概念图做场景建设，照顾细节、光影、材质。
基线：lixiang c87b41c，Unity 6000.3.25f1；概念参见 Concept.png。
目标：真正可试玩且可编辑的场景，匹配概念的象牙哥特拱廊、肋架穹顶、厚封印门、旧黄铜、深灰石板和撤离物件；明亮可读的冷暖照明。
结构：28 m 直径平坦战场，保留原碰撞与出生点。入口南、门北；旧版独立留存。新增独立 Arena、配置和测试场景。
细节：复合柱、雕刻檐口、窗棂、门板框层、维修夹具、供能管线、蓝绳箱、托位、清单和工具。无额外剧情机关。
效果：可运行的材质贴图、反射和法线；实际游戏相机冷暖照明；阶段变化随战斗时钟并正确暂停、恢复和离场。
验收：Unity 编译、资源依赖、现有碰撞签名一致、完整实际入口、六招两个阶段、近墙移动/跳劈/闪移、重试/返回；至少入口、近门、侧廊、道具和战斗实景截图逐张检查。性能报告仅限定本机采样。
交付：完整本地工程中的可玩场景、生成源、资源、使用说明和证据。不推送或合入团队分支。

用户修正（V2）：现有 V1 上半部过于简单；必须以约 23m 高的分仓尖券/交叉穹顶、大束柱、厚重主拱、雕花柱头、上层回廊和多级檐口重做恢弘与复杂层次。以实际 Unity 渲染对比 V1 和概念图，不把原来的简化圆顶视为完成。
