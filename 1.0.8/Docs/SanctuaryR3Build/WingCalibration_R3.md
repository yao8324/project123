# 羽翼 R3 动作校准

目标：慢走时完整翼体保持在 1.65 m 宽度内，同时维持实体羽片刚性、骨段长度和原有动作时间。

原始 FK 平滑插值在 WingOpen=0.12 时令铰链整体撑到约 1.799 m；羽片扇角不是主要原因。

本轮将传给 FK 的低区间量映射为：
- WingOpen ≤0.12：FK = WingOpen ×0.70。
- 0.12 < WingOpen <0.40：FK 从0.084连续接回0.40。
- WingOpen ≥0.40：FK = WingOpen。

WingOpen 动画数据、展开/折叠先后顺序、完全开/合端点不变。骨长及羽片尺寸不随动作缩放。这是对原设计精确 smoothstep 的实现修订，不能声称完全复现原始插值曲线；最终以动作连续性、姿态尺寸和碰撞净距共同验收。

羽片几何调整：初级宽0.22 m，次级0.20 m，覆羽0.18 m，均仍在设计范围内；中央肋高改为22 mm。每侧19枚不变。宽度增加仅缓解间隙，不代表已验证相邻重叠15–25%。

验证：WingRevisionCheck.json 记录全部67帧慢走宽度及典型冲刺/跳跃尺寸。尚需逐帧羽片互穿、翼根与肩甲、背饰净距，完整动作视频及Unity实景复核。
