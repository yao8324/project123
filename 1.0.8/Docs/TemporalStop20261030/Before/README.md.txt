## 打开项目

- Unity：**6000.3.25f1**（Unity 6.3 LTS）。
- Unity Hub 添加本文件所在的 **`1.0.6/`**，不要添加外层 Git 仓库目录。
- 主场景：`Assets/Scenes/MilanLibrary_Magic_V6.unity`。
- 等待资源导入、Package 解析和脚本编译完成，检查 Console 后进入 Play Mode。
- Build Settings 第一项为 MilanLibrary_Magic_V6；旧 LibraryMain 仍为第二个启用场景，备份场景不作为启动入口。

首次下载应使用 Git LFS。以下命令获取 `program` 分支已提交的工程：

```powershell
git lfs install
git clone --branch program --single-branch https://github.com/yao8324/project123.git
cd project123
git lfs pull
```

不要仅复制脚本或场景；必须同时保留 Assets、所有对应 .meta、Packages 和 ProjectSettings。GitHub 源码 ZIP 是否包含 LFS 实体取决于仓库设置，推荐 Git + LFS。若模型文件内容以 `version https://git-lfs.github.com/spec/v1` 开头，它仍是指针，需要下载实体。首次导入需要可访问包源与 Git 依赖。

## 本版已实现

- **环境漫游：** 城堡图书馆、书架与桌面陈设、第一人称剑盾和持握手部；移动、重力、接地跳跃、冲刺、蹲下和碰撞。
- **统一 UI：** Esc 菜单、探索指南、馆藏空状态、功能概述和探索入口。页面采用棕金配色、逐行分隔与悬停提示，中文使用项目内 TMP 字体资产。
- **可用设置：** 默认高画质；均衡/高画质按钮与 F8/F9 实际切换；鼠标灵敏度支持 0.25～3.00 倍调整。
- **按键换绑：** 探索指南中点击可用按键修改绑定，支持冲突检测、取消、恢复默认与跨运行保存；左键攻击/锁定鼠标、右键吞印/格挡固定，不可换绑或分配给其他操作。
- **魔法书交互：** 3 米中心射线检测；书、魔法阵和底座使用统一交互区域，短暂移开时保留提示，遮挡、超距和打开 UI 时清除。
- **视觉修订：** 地毯重叠闪烁修正；魔法书、地球仪展示位置与动画节奏调整；入口墙面、装饰和门洞修订。
- **自动魔法大门：** 宽幅双扇门、深色门板、黄铜与紫晶封印；靠近开启、远离关闭，门口停留保护及关闭中反向开启；关闭时搭接与压条遮住中央缝隙。
- **禁书守卫战斗：** 独立封印大厅、分段感知走位、五种法术/冲撞及刃杖近战攻击、二阶段、追踪禁页、吞印、共用体力防御、暂停、胜负、重试和返回。当前主场景使用新蒙皮模型、85 根骨骼、17 段导入动作及 2 段新增近战动作，配套金紫符文法环、禁页拖尾、双螺旋激光、裂地金屑与冲撞光带。动作由战斗状态计时驱动，当前参数与 AI 行为以上述近期修订为准。已移除无引用的 138 个旧 Boss/特效资源及 3 个旧生成脚本，保留在用竞技场结构与碰撞。详见 [骨骼动作与特效接入记录](Docs/BossDesign/CombatV2/README.md)。

## 试玩 Boss

1. 打开主场景并进入 Play Mode，靠近大厅与地球仪相平的《星图与魔法笔记》，按 **E** 打开独立试炼界面，再点击“深入探索”。主菜单和书柜上的普通书籍不提供战斗入口。
2. **左键**三段剑术连斩；**右键按下**吞印，并在举盾最初 0.22 秒内可弹反近战；**按住右键**格挡正面攻击。攻击、技能、格挡和吞印共用体力；耗尽破防，松开防御键、停手后延迟恢复。吞印 +25 力量，满值时下一次命中的剑击伤害提升为 1.65 倍。**1 重斩、2 盾击、3 突刺、4 回旋**，具体消耗与冷却见属性页。WASD 移动，点按 Shift 沿方向突进（4.8 米 / 0.24 秒，20 体力 / 0.85 秒冷却），按住继续奔跑；只有极限时机成功闪开攻击才触发短暂减速和彩色残影。Space 跳跃、C 蹲下。
3. Boss 在观察阶段选择接近、后撤或侧移路线，收招时不会自动跟随玩家转向。弹幕前先闪现后撤，再挥手召出头顶禁页、第二次挥手发射；禁页会持续追击，需要及时变向、格挡或吞印，近身锁向后侧闪。光束蓄力前 1.6 秒实时追踪，最后 0.65 秒金线锁定，此时侧移躲开，发射后方向固定。扩散圆环用跳跃躲避。裂地以 10.5 米/秒推进，每段预警 0.65 秒后爆发，需及时侧移。冲撞预警末段锁定直线，释放后几乎瞬间到达，应在预警时侧闪；随后金紫拖尾和残影消散，保留 1.45 秒收招反击窗口。残影本身没有追加伤害。
4. Boss 靠近时会预备刃杖横斩，侧退或及时举盾弹反；盾击和累积失衡也可打断。**I** 打开个人属性与装备，拖动模型查看正背面。Esc 暂停后可继续、查看属性装备、设置、查看固定战斗按键或返回图书馆；胜利/失败后可重试或返回。暂停期间冻结位置、重力速度及战斗计时。

战斗使用原 Input System；不会另建玩家或 EventSystem。设计、实际差异、资源路径和验证证据见 [Boss 实现与验证](Docs/BossDesign/ImplementationAndVerification.md)。

## 突进与极限闪避

点按 **Shift** 立即沿 WASD 输入方向突进，没有方向输入时向前；持续按住 Shift 继续奔跑。使用换绑后的冲刺键时，突进也跟随该绑定。

| 项目 | 当前参数 |
| --- | --- |
| 突进距离 / 时长 | 4.8 米 / 0.24 秒 |
| 消耗 / 冷却 | 20 点共用体力 / 0.85 秒 |
| 极限闪避判定窗口 | 突进开始后的 220 毫秒 |
| 减速与彩色残影奖励 | 0.75 秒；前 0.45 秒世界速度 25%，后 0.30 秒平滑恢复 |

奖励要求攻击真正到达突进前的位置，而玩家已移开至少 0.6 米并脱离实际攻击范围；普通突进不会自动减速。每次突进最多奖励一次，受击、格挡接触或吞印取消同帧候选奖励。突进保留碰撞且没有额外无敌时间；暂停、失焦或退出战斗会清理奖励和时间倍率。

| 操作 | 默认输入 |
| --- | --- |
| 移动 / 环视 | WASD / 鼠标 |
| 突进 / 奔跑 | 点按 Shift 突进 / 按住 Shift 奔跑 |
| 跳跃 / 蹲下 | Space / C |
| 打开菜单、返回上一页或关闭 UI | Esc |
| 个人属性与装备 | I，或 Esc → 属性与装备 |
| 三段连斩 / 举盾、弹反、吞印 | 鼠标左键 / 右键（固定） |
| 重斩 / 盾击 / 突刺 / 回旋 | 1 / 2 / 3 / 4（固定） |
| 重新锁定鼠标 | 鼠标左键（漫游状态） |
| 查看魔法书功能概述 | 瞄准可交互区域，3 米内按 E |
| 均衡 / 高画质 | F8 / F9，也可在设置页点击 |
| 修改按键 | Esc → 操作说明 → 点击右侧按键 |
| 修改灵敏度 | Esc → 设置预览 → 拖动灵敏度滑条 |

打开主 UI 时暂停玩家移动、重力与视角，释放鼠标；关闭后从原位置和运动状态继续。Esc 始终保留安全返回能力，换绑等待期间 Esc 取消。F8/F9 与方向键备用移动绑定保留，不分配给其他操作。

按键保存到 `Application.persistentDataPath/input-bindings.json`。画质和灵敏度调整目前只在本次运行内生效；下次运行回到默认。音量功能尚未接入。

## 馆藏逻辑与功能边界

**馆藏只代表用户成功导入的文件。** 装饰书、魔法书和 DemoBookRecord 演示资产不是用户馆藏；当前未接入导入服务，馆藏显示为空。界面中的导入、检索、阅读预览不代表真实业务已经完成。

P0 仍为：**导入资料 → 生成书籍 → 归档书架 → 搜索定位 → 打开阅读**。后续通过 LibraryDatabase 管理 KnowledgeBook，用户文件与 JSON 元数据写入 `Application.persistentDataPath`，不得写入 Assets。

计划格式策略：TXT/Markdown 在 Unity 阅读，图片在 Unity 预览；PDF、Word、PPT 保存元数据并由系统默认程序打开，P0 不承诺解析 Office/PDF 正文。

“深入探索”已接入独立 Boss 战首版；它是竞赛主题的扩展玩法，不把装饰书或战斗数据计入用户馆藏。AI、RAG、多人、账号、真实资料导入/检索/阅读仍未实现。详细接入契约见 [馆藏 UI 设计](Docs/CollectionUIDesign.md)。
