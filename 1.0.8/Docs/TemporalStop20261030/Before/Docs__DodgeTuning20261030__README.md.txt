# 突进与奖励手感调校 · 2026-10-30

按用户试玩反馈，延长突进与奖励窗口，降低突进的消耗和冷却，保留“成功躲过实际攻击才奖励”的规则。通过 Unity MCP 调整当前 1.0.6 工程。

| 参数 | 修改前 | 当前 |
|---|---|---|
| 突进距离 | 4.2 米 | 4.8 米 |
| 突进时长 | 0.16 秒 | 0.24 秒 |
| 共用体力消耗 | 22 | 20 |
| 冷却 | 1.1 秒 | 0.85 秒 |
| 极限闪避窗口 | 100 毫秒 | 220 毫秒 |
| 减速 / 残影奖励总时长 | 0.48 秒 | 0.75 秒 |
| 25% 世界速度保持时长 | 0.28 秒 | 0.45 秒 |
| 平滑恢复时长 | 0.20 秒 | 0.30 秒 |

残影停止采样的时间由奖励总时长减去单个残影寿命计算，随时间减缓同步延长并渐隐。点按突进、长按奔跑、方向选择、空中次数、墙体阻挡、真实命中和同帧接触取消奖励沿用现有机制。

## 最小验证

[MinimalChecks.txt](MinimalChecks.txt) 的 9 项全部通过：4.8 米 / 0.24 秒位移、消耗 20 体力、0.85 秒冷却、体力不足拒绝；200 毫秒时真实闪开横斩可奖励，221 毫秒不奖励；减速和残影延续至 0.63 秒，0.75 秒后恢复；突进进入命中区仍受伤；Esc 立即清理奖励。

仅运行这组 MCP Play Mode 检查，没有全量测试或构建。最终 Unity Console 0 Error / 0 Warning，已退出 Play Mode，时间倍率与物理步长恢复原值。手动体验时，在 Boss 攻击临近时按 A / D / S + Shift；成功时出现彩色残影，过早离开和直接撞进攻击都不授予奖励。
