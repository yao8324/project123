# Arcane Archive：逆誓剑与缄眼盾

日期：2026-10-23。制作环境：Blender 5.2.3 LTS，Blender MCP 1.8。

本目录包含根据 `Oathbound_SwordShield_Design_v1.png` 制作的两件独立、可编辑的三维装备首版。模型通过 Blender MCP 在独立场景中创建，源文件、FBX 与实际渲染结果均保存在此目录。没有修改 Unity 工程或此前的 Boss 模型。

## 设计与结构

**逆誓剑 / Oathbreaker**：连续的双刃钢剑、中央凹槽和旧金铭文；护手采用展开书页般的轮廓、包边和细小纹饰；中央为紫晶圣龛。一侧有象牙色封印和三枚封钉。椭圆皮革握柄、金属连接颈和镶石剑首均为实体结构。

**缄眼盾 / Veiled Eye**：带厚度的凸面盾壳、卷边金框、哥特窗花纹与低浮雕叶片；中央封印由独立弧面骨片、封钉和紫晶组成。背面具有皮革衬垫、独立握把、弯曲支架、臂带、搭扣及铆接部位，并留有手指和前臂空间。

两件装备采用黑钢、旧金、暗红皮革、象牙色封印和克制的紫光。细节是可编辑网格；这是一版按概念转译的风格化模型，并非逐像素还原原设计图的最终雕刻资产。

单位为米，根对象缩放为 1。下表尺寸为含包边及装饰的实际包围盒；盾的厚度包含背后的握持结构。

| 模型 | 尺寸，宽 × 厚 × 高 | 模型网格部件数 | 三角面数 |

| 逆誓剑 | 0.247 × 0.053 × 1.050 m | 11 | 19,034 |

这是较详细的第一人称源模型。尚未制作远景 LOD，也未对最终移动平台或多人场景做性能验收。

## 后续动作接入

两件装备按刚体持握设计，不需要为钢剑或盾壳添加软体蒙皮。

1. 将 `Oathbreaker_Sword_ROOT` 挂到右手骨骼或右手武器挂点。其原点位于握柄中心。
2. 将 `VeiledEye_Shield_ROOT` 挂到左手骨骼或左手武器挂点。其原点位于盾背握把中心。
3. Blender 中剑尖指向局部 `+Z`，盾正面朝局部 `-Y`。FBX 使用 `-Z Forward / Y Up` 导出；接入引擎时仍须按实际手骨方向校正挂点旋转。
4. `Socket_Grip_R`、`Socket_Grip_L` 表示握持位置。`Socket_Forearm` 用于对齐左前臂；盾上缘和下缘也有参考挂点。
5. `Socket_BladeBase` 与 `Socket_BladeTip` 供后续剑刃轨迹、拖尾或攻击检测使用。这两个空对象本身不会产生碰撞或伤害。
6. `FX_SwordSeal`、`FX_ParryOrigin` 是特效参考点。名字含 `Magic channels` 的网格和 `VioletSeal` 材质与主体分离，适合后续做格挡、防反时的发光变化。

本次不包含人物手臂、持握动画、格挡逻辑、攻击碰撞体、伤害或防反判定，也没有将模型装入 Unity 场景。

## 材质与 UV

全部模型网格具有 `UV0` 和有效材质槽。Blender 工程的材质使用内置节点与程序纹理，不依赖丢失的外部贴图。

FBX 已保留网格、UV、材质分组与挂点。Blender 的程序噪声、凹凸和发光节点不能通过 FBX 完整变成 Unity URP 材质；在正式进入 Unity 前，需要烘焙 PBR 贴图并配置 URP Lit/发光材质。这一步尚未完成，不应把 Blender 渲染效果当作已经通过 Unity 验收的效果。

## 已执行验证

- 分别重新打开剑、盾的 `.blend`，保存为独立工程。
- 检查全部部件：没有开放边、非流形边、孤立顶点或零面积面。
- 检查 UV、材质槽和握持原点。
- FBX 导出后在空场景重新导入：网格三角面数一致，尺寸误差小于 0.1 mm。
- 渲染并目视检查剑的正面、斜侧面、护手近景，以及盾的正面、斜侧面、背面、封印近景。
- 上述检查不等同于自动证明所有装饰之间都无相交；接入实际人物后，还需要检查第一人称视野、手掌姿态、动作穿插和碰撞代理。

## 可复现脚本

- `build_weapons.py`：生成独立剑盾场景和初次 FBX/源文件；已有同名武器场景时停止，避免覆盖人工修改。
- `verify_and_render_weapons.py`：在独立 Blender 后台进程中重新打开文件、完成检查并输出渲染；同时把初次生成的依赖库文件保存为普通 Blender 工程。
- `build_review.py`：读取独立源文件，创建同屏展示文件并渲染。

生成和验证脚本会更新本目录的同名输出。若已人工精修，应先另存版本再重新生成。
