## Unity入口

使用本机已安装的Unity **6000.3.24f1** 打开`D:\project123\1.0.6`，打开`Assets/Scenes/IMMonsterContest20261107.unity`再运行。原Milan及战斗演示场景保留。目标25版未复验；本轮没有下载安装编辑器。

重新构建可执行`ArcaneArchive.Visuals.Editor.ContestSceneBuilder.BuildWindows`，或菜单`IM Monster/Build Windows contest player`。默认输出工程下`Builds/IMMonsterContest20261107`，本轮通过环境变量`IM_CONTEST_OUTPUT`指定到`D:\IMMonster_Contest_20261107`。构建只选择比赛场景，临时产品名和版本号会恢复；不需要修改共享Build Settings。重新生成场景会覆盖本轮比赛场景，请先保存自己的场景修改。
