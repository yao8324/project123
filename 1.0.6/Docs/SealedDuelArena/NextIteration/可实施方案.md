# 星空封印斗场 · 下一轮可实施方案

状态：供管理者审阅的新增方案。当前版本已完成最新打包，真实 UI 鼠标点击“继续战斗”的自动检查通过；原生真实UI点击继续／返回及图书馆环境恢复均通过。新增交互机制未植入游戏；星空与暗色材质已实施。

## 1. 场景与星空

破口上方增加稀疏星点、少量不同亮度星群和低饱和靛蓝天空；星点在天空层，不悬浮在室内。石材以深灰蓝／炭灰为主，铜饰保持旧金色，避免全部压成黑色。
以当前截图作对照，首轮试调曝光降低 0.3 EV；墙面反照率降低约 10–15%，不是同时大幅压暗所有灯。保留 Boss 轮廓光、攻击预警、地面可走边界和石灯。以上是试调起点，需实机比较。
修改位置：`SealedArenaAtmosphere.cs` 的天空、环境光；`SealedDuelArenaBuilder.cs` 的 PrepareMaterials / Lighting / Volume。天空需随返回图书馆恢复。

## 2. 当前确认机制（替代旧水晶提案）

以《锁链护晶_音效与特效清单.md》为准：悬浮盘旋的紫符文锁链保护水晶，先破链再破晶；三路紫色供能汇集Boss，每枚同时提供10%减伤和一份持续回血。断链后仍供能，破晶才取消对应增益／灯效并留下暗淡残晶；全破触发一次硬直。
回血数值、锁链耐久和硬直时长尚待平衡。完整八类声音、五种Boss攻击音和十五项VFX见新清单。

## 3. 可选扩展

外围少量残垣、魔法阵增益留作独立扩展，不与本次锁链护晶机制混为一项。现有Guard并非已确认的冲刺体力系统。

当前四个声音文件在 `Assets/Audio/Boss/`：RunicBolt.wav、SealWarning.wav、SealImpact.wav、Absorb.wav；引用来自 `Assets/Art/ForbiddenWarden/WardenEncounter.asset` 和 `BossDefinition.cs`。

|事件|当前情况与实施位置|建议声音方向|
|---|---|---|
|玩家普通／强化发射|BossEncounter.FirePlayerBolt；拆分 shotSound|短促空气切割＋低音符文瞬态，强化版增加一层低频|
|Boss 飞页齐射|BossEncounter 发射飞页处同样使用 shotSound；改独立 bossVolleySound|纸页摩擦＋暗色法术冲击；整组播主音，单页降低音量避免叠爆|
|Boss 预警|进入 Telegraph 使用 warningSound|可辨认的低沉共鸣；预警与真正发射分离|

|水晶激活／断裂|新增 ArenaCrystal / BossPowerNetwork 事件|低音持续共鸣、玻璃脆裂与能量断线；空间定位随水晶|

实施时新建 `CombatAudioProfile` 存放每个事件的多个变体和音量，而不是覆盖旧 WAV。BossDefinition 保留兼容字段，迁移后再清理。播放器分 Player / Boss / Impact / Ambient 混音组；环境声做 3D，玩家受击与关键确认偏 2D；限制同时播放数量，统一响度后再试听。
试听页提供 JaggedStone 的 7 条原始魔法素材，CC0，未做降调／混响，也未替换游戏。它们只供挑选音色，不把同一条素材直接复用于所有攻击事件。下一步按你选的编号剪成发射、蓄力或命中片段；石裂／甲胄／链条层仍需补选专用素材。

## 6. 实施顺序与验收

1. 星空、材质、灯光：固定入口／侧面截图比较，确保 Boss、地裂预警和可走路径在暗处仍可见。
2. 拆音效事件与基础受击：先完成普通发射、Boss 齐射、受击、格挡、破盾六类；在实际混战中验证响度和重叠限制。
3. 三水晶闭环：先破链再破晶、可瞄准、减伤与回血实时变化、最后一枚硬直、重试重置，HUD 可读。验证阶段转换／死亡同帧破碎不会重复触发。
4. 少量外圈障碍：测试角色胶囊、Boss 冲刺、投射物和自动瞄准；不能沿用旧无障碍测试直接宣称通过。
5. 悬浮锁链保护属于本轮核心；魔法阵与狂暴分支后置。
