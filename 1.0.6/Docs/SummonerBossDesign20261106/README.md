- 用户要求由助手继续制作模型，同学负责正式场景。现已完成五类召唤物、可拆甲胄和独立投射物的模型首版，见[资产清单与接入说明](../SkeletonMinion20261106/README.md)。Boss 仍沿用已有初版。

- 房间只是独立的场地与尺寸参照，没有战斗控制器或第三 Boss AI，也未替换正式关卡。Unity 菜单 `Tools > IMMonster > Build Summoner Test Room` 可重建；重建会覆盖此测试场景和房间 Prefab，手工修改请另存。
- 新增脚本：`Assets/Scripts/Visuals/Editor/SummonerBlockoutBuilder.cs`。Unity 6000.3.24f1 批处理编译与生成通过，退出码0；重新打开保存后的场景，确认6个实体碰撞体、地面及四墙／屋顶射线检查通过。验证日志：`Logs/SummonerBlockoutBuild.log`。手动复查可打开场景查看布局，或从上述菜单重建后检查 Console 的 `SUMMONER_BLOCKOUT_OK`。

## Boss 技能

| 技能 | 设定 |
| --- | --- |
| 黑魔法召唤 | 吟唱约4秒，从地图各个位置随机召唤3～5个亡灵。墙上或地面出现魔法阵，亡灵从阵中钻出。 |
| 紫色骷髅冲击 | 向前方三个角度放出紫色骷髅冲击。 |
| 飞行撞击 | 飞起来向玩家撞击，跟踪约2.5秒，速度为玩家正常步行速度的两倍。 |
| 魔法匕首 | 玩家接近时，召唤魔法匕首向前方小范围挥刀。 |

## 亡灵兵种与攻击

骷髅兵可穿不同程度的残破甲胄，眼中冒鬼火。

| 兵种 | 形象与攻击方式 | 攻击伤害 | 基础生命 |
| --- | --- | --- | --- |
| 弓箭手骷髅 | 从背后箭筒取箭、搭弦，向玩家位置以约45°仰角抛射；取箭到发射约3秒，箭矢飞行、下落时间按距离计算。 | 10 | 两次普通攻击击杀 |
| 双手锤骷髅 | 身材魁梧，双手持锤，举过头顶蓄力后砸下，整个过程约3秒。 | 20 | 三次普通攻击击杀 |
| 剑盾骷髅 | 用剑挥砍，可用盾格挡；格挡频率不能太高，格挡时玩家攻击无效。 | 15 | 两次普通攻击击杀 |
| 砍刀骷髅 | 挥舞砍刀近战攻击。 | 10 | 一次普通攻击击杀 |
| 半透明亡灵 | 参考《皇室战争》亡灵形象，半透明、稍难看清，半浮空但保证玩家能攻击到；向玩家投掷火球。 | 15 | 一次普通攻击击杀 |

### 预警与应对

- 弓箭：落点提前出现红色闪烁光圈；玩家可挥剑打落箭矢、用盾格挡或躲开。
- 锤击：落点提前出现红色闪烁光圈。
- 火球：落点提前出现红色闪烁光圈。

## 护甲与破甲眩晕

- 按骷髅兵的披甲数量和覆盖面积设置护甲，为基础生命的0%～50%，相当于额外血量。
- 原本有护甲的士兵，护甲归零时眩晕2.5秒，期间不能进行其他动作。
- 眩晕表现：摇头晃脑，眼睛变成星星，头顶出现动画中常见的眩晕圈。
- 初始护甲就是0的士兵，不会因此触发眩晕。

## 按当前普攻伤害换算

当前普通攻击基础伤害为30。按未强化普通攻击、无护甲的基础生命换算：

| 兵种 | 基础生命 | 护甲范围 |
| --- | --- | --- |
| 弓箭手 | 60 | 0～30 |
| 双手锤 | 90 | 0～45 |
| 剑盾 | 60 | 0～30 |
| 砍刀 | 30 | 0～15 |
| 半透明亡灵 | 30 | 尚未指定是否披甲 |

护甲是额外血量，加甲后的实际击杀次数可能增加。其他未给出的伤害、范围、冷却等参数，等用户继续补充。
