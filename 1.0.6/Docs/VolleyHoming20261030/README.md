# Boss 后撤弹幕追踪加强（2026-10-30）

通过 Unity MCP 调整当前 1.0.6 的禁页弹幕。主要问题是旧转向速度和总转向余量偏低，而且出手时继续使用较早锁定的位置；玩家在后撤与蓄力期间移动后，禁页容易从起飞时就偏离。

## 当前行为

每一枚禁页释放时重新采样玩家当前胸部位置，保留原来的散射间距，再持续弯向玩家。悬浮冠环的姿态目标与真正发射目标分开处理。

| 参数 | 原值 | 当前值 |
| --- | --- | --- |
| 追踪转速 | 10°/秒 | 95°/秒 |
| 累计转向上限 | 12° | 85° |
| 启动延迟 | 0.12 秒 | 0.04 秒，Boss 专用 |
| 最长追踪时间 | 1.15 秒 | 1.8 秒 |
| 前向追踪夹角上限 | 约 66° | 约 87° |
| 近身停止追踪 | 1.7 米 | 1.7 米，之后不重新锁定 |
| 弹速 | 22 米/秒 | 22 米/秒 |

保留弹幕发数、发射间隔、伤害、格挡与吞印。飞过玩家后停止追踪，不会转回来二次追击；墙体继续阻挡飞行。玩家弹体仍使用原有 16°/秒、9° 总转角、0.12 秒延迟及 0.85 秒有效追踪时间。

## 修改文件

- Assets/Scripts/Core/BossDefinition.cs：Boss 独立的追踪延迟、时限与近身锁向距离，以及更强的转速/转角默认值。
- Assets/Scripts/Core/BossCombatBehaviours.cs：区分 Boss 与玩家弹体的追踪规则。
- Assets/Scripts/Core/BossEncounter.cs：每枚禁页以最新玩家位置发射，更新提示文案。
- Assets/Art/ForbiddenWarden/WardenEncounter.asset：实际运行参数。
- README.md、CHANGELOG.md。

Before 为本轮开始前的快照，FilesChanged.json 包含修改文件与前后 SHA256。
