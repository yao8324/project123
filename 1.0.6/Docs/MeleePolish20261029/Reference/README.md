## 迁移设计建议

- 节奏：短预备 → 很快的有效斩击 → 沿惯性延伸 → 松弛回收。轻击可从总长约 0.45–0.65 秒开始调节，重斩保留更明显蓄势。
- 连击：交替横斩/反向斩/下劈，输入缓存应允许下一击从收势接出，避免每次先回待机再启动。
- 反馈：命中才做极短顿挫、轻微回弹和定向镜头冲量；未命中维持顺畅。不要持续左右摆动镜头。
- 特效：刃口运动路径为主体；短寿命、半透明宽痕配细亮边，命中时在接触位置加细碎火花。沿用项目旧金/紫色封印风格，勿将整个项目变为霓虹赛博风。
- 四技能各有轮廓：重斩是高位蓄势后强下劈；盾击是短后拉再猛烈前推；突刺是身体压低、直线冲进；环斩是跨身拉开后宽弧挥过。不同技能使用不同闪光方向与强度。
- 近战身份保留：攻击与镜头反馈不应自动大幅扭转玩家瞄准；突进受角色碰撞约束。
