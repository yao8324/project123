# IM MONSTER 完整整合试玩

整合来源：剧情交互反馈 de003e6 与三水晶斗场 ec365aa。

启动 Mac 版 IM MONSTER.app 后选择：
- 剧情探索：原有完整剧情流程，新增常驻准心、真实交互状态提示、分类动作音效和7种环境声。
- Boss斗场：哥特式封印斗场、三座护晶锁链、每晶10%减伤与持续回血、破晶逐路断供、全破2秒僵直。

两者作为独立试玩模式提供，入口不表示剧情已经自动衔接到Boss战。当前未加入三结局。

完整下载ZIP包含 Mac程序、UnityProject源码工程、当前验收资料。Mac程序是本轮新构建；Windows玩家可在Unity 6000.3.25f1安装Windows Build Support后从工程构建，包内未冒充提供新版Windows程序。

Unity工程打开 Assets/Scenes/IMMonster_FullDelivery.unity，三场景已写入Build Settings。源码包中的Git LFS资源已还原为实际文件，解压工程无需先配置Git LFS。

操作：WASD移动，鼠标观察，E交互，Esc暂停；斗场左键秘文弹，右键吞印/按住格挡。新法杖候选仍待用户选择；本版延续目前发射声，其余已选声音按备注配置。
