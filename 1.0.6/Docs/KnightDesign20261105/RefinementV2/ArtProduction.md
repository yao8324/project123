# 终扉守誓者：精细版本制作说明

本文件是当前 V2 的后续制作规格，不代表全部资产已经实现。实际玩法、视频时间点、八招数值和原型边界以 [Design.md](Design.md) 为准；世界观依据见 [资料核对](../SourceAudit.md)。这里将“参考洛希德”的方向落实为可建模、可做动作、可验收的方案。

## 1. 角色首先应该给人的感觉

远看是一条站在封印门前的银色竖线，动作开始后才展开成宽阔的金色弧线。安静时克制、稳定，交锋时转身、退步、回旋一气呵成。神圣感来自职责、秩序与装备完整性，而不是羽翼数量或全身泛光。

他在保护一套仍在运转的设施，并不是等玩家来挑战的表演者。站姿、转阶段和停战都要留下朝门侧回护的倾向，但战斗中不能强制背贴门、取消玩家绕后的空间。面甲遮住个人表情，把细微态度交给头部角度、持柄松紧和重心。个人姓名、真实年龄与信仰不在美术制作时擅自补全。

参考中长发的运动感改为封缄长带，长柄武器保留挥舞时的长线条。不要直接复制参考人物的脸、盔甲纹章或武器图案。自己的识别点是：匿名象牙面甲、完整双环、分层银甲、十二条封缄带、带封印亮芯的长柄刃器、短时展开的腕盾。

## 2. 造型从大到小怎么做

第一层是比例与负形。目标盔顶约 3.2 米，冠环略高；腰身收窄，肩甲不再堆成横向方块。双腿之间、上臂与躯干之间留出能从第一人称看清的暗色间隙。长柄刃器约 4 米是视觉总长，不能因此默认为整条柄都有伤害；有效范围仍读取招式配置。

第二层是承力结构。胸甲采用略拱的中央面和两侧收折面；腹甲逐层搭接，弯腰时能滑入上一片。肩甲从肩关节外侧向后收，肘窝、腋下、髋与膝后留黑钢和织物，不用实心甲片封死。小腿前甲拉出细长折线，脚甲前尖适度，不能让脚尖看起来比脚底落点长出半米。

第三层才是权限纹与磨损。旧金线沿甲片结构边走，在胸口、腕盾和武器亮芯汇聚；不要在每一块甲上重复发光大符号。刻纹可以表现源石供能与封印用途，但不额外赋予“读心”“复活”之类没有依据的能力。

| 部件 | 建模与装配要求 | 动作时必须核对 |
| --- | --- | --- |
| 面甲与头盔 | 面甲是整体浅色弧面；眼缝细而可读；后扫冠饰把视线引向双环 | 低头蓄势时眼缝不被胸甲挡死；头盔不穿肩甲 |
| 胸腹与裙甲 | 统一厚度与倒角尺度；腹甲四层；裙甲分前后侧，不做一个硬桶 | 扭腰和抬膝能成立；旋锋时裙甲不贯穿大腿 |
| 臂甲与手 | 肘腕分别留旋转余量；右手握柄、左手能辅助扶柄或施法 | 所有命中帧拇指与握点一致；双手 IK 允许释放与重新抓握 |
| 腿足 | 髋膝踝有明确骨点；黑钢关节提供深色对比 | 脚掌着地、转轴、刹步依次发生；停止移动后不继续原地跑腿 |
| 长带 | 从后脑和上背分组垂落，长度有层次；近肩部分更重，末端更轻 | 回旋有滞后，收招能回落；不甩到镜头前遮住全部武器 |
| 双环 | 两个环有结构厚度，刻片不均匀堆满一圈 | 一阶段相对稳定；二阶段缓慢错位，不能高速旋转制造视觉噪声 |
| 长柄刃器 | 刃、柄、护手、尾配重的质量关系清楚；用方向性纹理说明刃口 | 第一人称近距离仍能分清刀口与握柄；碰墙时不改变伤害范围来掩饰穿插 |
| 腕盾 | 格御时从腕部展开薄片和权限环，主体仍有可辨认的实体轮廓 | 正面防护与实际120°一致；收盾后不要残留一块看似仍无敌的大盾 |

当前分件网格可用作比例与挂点参考，正式版需要重新拓扑、UV、蒙皮与法线制作。LOD0 可从约 20k–35k 三角面起步，LOD1 约减半；这是预算起点，必须以目标机测量收敛。材质尽量合并为银甲/黑钢、象牙与织物、旧金、发光等少量槽位，避免当前每片独立 Renderer 的结构直接进入发行版本。

## 3. 色彩、材质与两阶段变化

主色用中亮度冷银灰，象牙色只放面甲与长带，黑钢填关节，旧金用于边缘与权限。可以从银灰约45%、暗部30%、象牙及内衬15%、旧金与发光10%的视觉面积起步；不把它当硬性材质统计。

银甲需要宽而柔和的高光，磨损集中在刃口附近、膝与前臂，不把整件甲涂满随机噪声。黑钢保留边缘反射，最低画质也不能吞成纯黑洞。长带偏哑光，末端带浅灰压印；金雷发光与静态金属分开，停手时能看到武器本体。

二阶段是承压而非变种。双环错位、胸前导流线亮起，长带略微抬升，已有损伤加深；轮廓和武器保持。门缝随之缓慢增强，表示他在维持封印同时调取更高负荷。此处是演出方案，不新增一个需要玩家打掉的“门血条”。

## 4. 八招的精细动画与特效交接

动画按战斗时钟采样，前摇、锁向、命中和恢复由战斗层决定。逐帧对齐应以 [八招时序表](Design.md#5-当前八招与设计用途) 为准。正式动画不再各自触发一次伤害，避免动画事件与当前判定重复结算。

| 招式 | 身体与兵器如何交代 | 释放画面与声音 | 制作验收重点 |
| --- | --- | --- | --- |
| 誓舞连锋 | 前脚承重、肩胯反拧，刃先藏侧后；首扫后重心换脚，再从另一侧回扫；第三击先提柄再下压 | 每次刃过中线才亮金弧，刃尾渐细；双拍金属声与第三击重音分开 | 0.18/0.95/1.72s 的姿态确实经过玩家方向；收招前不能假装已经停稳 |
| 贯门突刺 | 后腿压低，柄与视线同轴；推进有启动、跨步、刹停三段 | 窄而长的锋线，冲势终止时向前散掉；单次长蓄音接短促释放 | 锁向后不再偷偷转向；墙前缩短的是位移，动画仍有刹停 |
| 封印飞矛 | 刃器回侧，先退一步再举腕召出三刃；身体持续面向玩家 | 三个待发刃逐个熄灭并发射，发射声等距且可区分；可吞提示独立于金色主体 | 待发刃数量和真正弹体一致；后撤不能穿墙；不要把头后金纹误画成碰撞弹体 |
| 地脉雷裁 | 刃先垂下，压柄将术式导向地面；头和肩明确朝地带方向 | 低位纹路先定形，再沿地面爆发；短石槽共鸣，不产生整面高雷墙 | 保留可跳的低位语义，空隙与实际矩形一致；不要画出不可跳的竖柱 |
| 收锋格御 | 长柄回侧，左臂抬到胸前，腕盾从小环展开成实体片 | 低音锁合，命中处局部亮起；挡住正面才触发有效防护反馈 | 玩家能看到盾侧和背侧；盾击拆防有后仰与收盾过渡；两次正面命中才反推 |
| 退界盾击 | 单独的压肩和收肘前摇，再向前送腕，不从受击中无预告弹出 | 短扇形金震与钝击声，体量小于刀光 | 可挡不可弹反的形状/提示明确；当前不加额外击退，后续若加需重测边界 |
| 回身旋锋 | 先显露转向，踩出切线步，躯干带刃回旋；第二次扫后用落脚结束惯性 | 两次清楚的宽金弧，中间仅留细尾迹；长带滞后于躯干 | 武器、肩胯、脚步与2.4m位移同步；不能一边脚站死一边整体滑走 |
| 悬誓落雷 | 举刃后收腿升起，视线压向锁点；三次落雷以腕和柄的小幅动作维持节拍，最后落地收势 | 三个地圈固定后，中→右→左竖雷；金白芯、细分枝、短地面环；雷声分别触发 | 玩家离开锁圈即安全；跳跃不绕过竖雷；落地与胶囊归位一致，打断立即清理 |

刃轨分“兵器真实运动的短尾迹”和“命中时的范围强调”。前者依 BladeTip 采样，后者寿命更短、边缘更软；两者都不能长时间覆盖模型。当前金弧是离散命中时的几何强调，后续改连续刃迹前须替换判定，不能同时保留两套伤害。

雷光分核心、辉光与分枝：核心清楚，辉光有限，分枝只补方向。当前已校正实际 LineRenderer 宽度衰减，避免宽度被重复缩小后几乎不可见。正式版补短暂地面接触亮斑、少量向外碎屑与空气扭曲即可，不增加遮住后续地圈的大烟柱。后处理开启/关闭时都要能读出范围。

## 5. 场景的最终构图

场景叫“终扉前庭”，是通向深层封印的承压空间。北侧封印门为视觉中心，入口在南。玩家首先看见门、门前骑士和两侧供能支路；再靠墙读到撤离与维修痕迹。源石在更深处，门后只有被遮挡的纵深光，不能直接摆在竞技场中央。

平面和碰撞尺寸沿用 [场景尺度表](../ArenaDesign.md#2-尺度与平面布局)：圆台半径14m，玩家出生(0,0.08,-5)，骑士出生(0,0,4)，门在北侧约Z=13.6。所有坐标相对 Arena 根。后续建筑精细化不移动这些点，除非重新验证八招、安全区和剧情站位。

| 视域层次 | 细化内容 | 对战斗的限制 |
| --- | --- | --- |
| 中心交锋区 | 深灰石大分缝、轻微使用磨耗、少量不发光嵌片 | 保持平整，不设台阶、散落书堆、可破坏掩体或突起沟槽 |
| 北侧门体 | 两根主肋、尖拱、厚实门扇、双环权限纹、细窄观察缝 | 门纹低于攻击亮度；门框不伸进常用侧闪线路；门后不可达空间不伪装成可探索通道 |
| 外环 | 立柱、壁龛、供能线与修复夹具；结构节奏疏密分组 | 半径10–12.5m仍可通行；大型装饰置于外缘，不把整圈变成柱间障碍赛 |
| 南侧入口 | 门框与撤离痕迹、空转移托位、可读清单 | 战斗边界封闭时有明确实体；文字在入战前可读，不迫使玩家挨打读日志 |
| 门后纵深 | 两层遮挡与少量设施轮廓、受控冷光 | 不展示源石本体；不靠不可见巨型面片投出异常阴影 |

建筑语言接续哥特图书馆的尖拱、肋线与旧黄铜，但减少书架和木作。图书馆保存知识，前庭承受封印压力；这里应更厚重、更空旷、更能承接人物剪影。地面分缝尺度大，墙面细节集中在门和少数壁龛，避免每一寸都满雕花。

## 6. 场景灯光和叙事如何服务战斗

主光从玩家左前上方擦过银甲胸面、肩和持柄手，门后冷光只勾边，外侧供能线是较暗暖色。环境固定金线和危险提示必须有亮度、宽度及动态差异：细、暗、稳定的是装饰；宽、明、收束倒计时的是攻击。竖雷出现时仍应看清下一圈位置和自己的左右出口。

二阶段门缝、胸纹、双环同步缓慢变化，不切镜头，不全屏闪白。正式版先烘焙静态建筑，再限制局部实时光与阴影；目前提高的原型补光不能直接当作最终灯光预算。检查720p/1080p、两档画质及后处理关闭，不能仅在一张高曝光截图中看起来正确。

空间叙事只做少量可核对证据：入口清单说明撤离尚未结束；门侧烧蚀和夹具说明已经尝试修复；两条供能支路说明封核心会牵连外层。它们支持双方立场，不增加必须收集的钥匙。台词中若采用具体撤离次数，要同时在清单或前置剧情中实现，不能只靠一句话补设定。

声景以低频设施共鸣和远处撤离动静建立压力。近战、飞矛、低位雷纹、竖雷分别有起音，释放声由真实命中/发射时刻触发。暂停不排队补播，停战时立即收掉持续攻击声。没有声音时，动作与几何仍应独立说明危险。

## 7. 资产制作顺序和通过条件

1. 冻结当前可走区域与八招时间线，确认武器握点、角色胶囊、刃迹和锁圈一致。
2. 做正式骨架、双手持柄 IK 与脚底植根；先完成一套连锋、一套旋锋和落雷升降，验证动作方式后再铺开其余招式。
3. 完成转身、侧步、后撤与刹停衔接；接着做十二条长带的分段骨骼、环的次级动作及失衡/停战过渡。
4. 按已验证姿态完成拓扑、UV、贴图与 LOD，合并材质和渲染器；再完成门、外环和少量叙事资产。
5. 补专用声音、克制的粒子与曝光控制，测试原有所有剑盾技能、暂停、失衡、胜负重试和返回。
6. 最后做真人完整战斗、目标机性能和独立包；剧情、多目标/友军与存档按公共契约接入，不能在美术生成器里暗加流程。

一招完成的标准包括：普通视野看得到前摇；锁向后提示可信；实际命中时兵器或术式确实经过危险区；闪开后不会被尾迹补伤；能看见收招；暂停/减速/打断不脱节。模型和场景精细化都必须逐招回到这些条件核对。
