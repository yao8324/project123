# 圣骑士场景：终扉前庭

> V1 布局推导保留。当前仍沿用半径和安全路径，已增加门肋、权限纹与外缘立柱；当前改动见 [V2 设计](RefinementV2/Design.md)。

## 1. 为什么在一扇门前打

场景的叙事中心是一道封印门，不是一座与故事无关的竞技台。骑士站在门前，玩家从外层进入：玩家要争取救援时间，骑士要阻止风险进入核心。两人的移动方向自然表达冲突，无需用复杂过场解释。

门后只提供深处仍有设施的光和低频共鸣，不露出源石本体。这样既保留“源石位于更深处”的空间层级，也为后续精细场景留下纵深。战斗区外缘可以看到两条状态不同的供能支路：一条通向外层、仍需维持，另一条通向深层封印、不能失守。

当前白盒只做圆台、围墙、门和灯。后续所有装饰都放到外缘或可控后景，中心保持平整，让玩家把注意力用于看剑、看盾和读地面预警。

## 2. 尺度与平面布局

坐标采用 Arena 根的局部坐标，Y=0 为地面，+Z 朝向封印门。下面是设计坐标，正式整合通过锚点定位，不能写死世界坐标；原型仍沿用旧会话在世界 X=160 实例化的历史行为。

| 区域/锚点 | 原型或建议尺度/位置 | 用途与后续要求 |
| --- | --- | --- |
| 主战斗圆台 | 半径 14 米、直径 28 米 | 足够容纳 4.8 米突进和 12 米地带；地面无高低差 |
| PlayerSpawn | (0,0.08,-5)，面向 +Z | 与 Boss 初始相距 9 米；完整看到前摇；不能出生在危险带里 |
| BossSpawn | (0,0,4)，面向 -Z | 身后仍有退让空间；不把背贴在门上制造无法绕后的盾防 |
| 封印门 | 中心约 (0,2.4,13.6)，宽 4.4、高 4.8 米 | 作为北侧视觉基准；碰撞不伸进常用侧闪区 |
| 入口方向 | 南侧，约 Z=-13 | 原型用围墙封边；精细版提供可辨认的入口门框和非战斗进入通道 |
| 外环通行带 | 半径约 10–12.5 米 | 留给长线躲避和环境观看；不堆书架、桌椅、锁链 |
| 战斗安全内圈 | 半径约 11.5 米以内 | 优先安排核心交锋；有效攻击不越过可见边界 |
| 玩家武器净空 | 常用路线至少 2.2 米宽、4.5 米净高 | 精细甲片、柱脚和门饰不能夹住胶囊或贴脸挡视野 |
| 剧情玩家位 | 建议 (0,0.08,-1.5) | 这是待验证候选；正式版不能未检测碰撞就强制传送 |
| 剧情骑士位 | 建议 (0,0,3.5) | 约 5 米对话距离；盾放低，武器不穿玩家 |

```text
                         北 / +Z
                  [深层封印门与门后光]
              [核心支路]        [外层支路]
           ┌─────────────────────────┐
        ／           骑士出生点          ＼
       │        平整、没有柱子的交锋区      │
       │                                 │
       │       突刺与地带预警可完整显示       │
       │                                 │
```

原型的围墙为 32 段直墙组成的封闭边界，半径附近留实体阻挡；圆台碰撞使用地面网格，不使用会因非均匀缩放变形的胶囊。后续门框和柱只替换外轮廓，不改变已经验证的地面和安全路径。

## 3. 空间叙事物件：少而能核对

| 物件 | 放置区域 | 传递的信息 | 互动与制作边界 |
| --- | --- | --- | --- |
| 撤离清单 | 入口旁壁龛 | 骑士确实尝试过撤离；仍有一批未完成 | 玩家入战前可读，关键事实另有主线提示，不强制找日志 |
| 外层供能沟槽 | 外圈地面至门侧 | 关闭核心会影响外面；双方争取的是同一条供能线 | 浅槽与发光遮罩，不做凸起绊脚结构；与攻击地带图案区分 |
| 修复夹具与烧蚀痕 | 门框侧面 | 已尝试局部隔离、修复，不能无限等待 | 2–3 处足够；不要把无数破损纹当作信息 |
| 空的转移箱托位 | 南侧后景 | 典狱长与救援线在继续行动 | 不摆一排可被攻击的平民；避免误导成可拾取装备 |
| 百年前镇压纹 | 门顶或外侧屏障 | 当前职责有历史来源，和玩家掌纹呼应 | 使用同一套三缺环语汇；不复制玩家环纹的全部功能 |
| 封印门观察缝 | 北侧门体 | 深处还有设施在运转，源石仍未被拿走 | 保留遮挡，不能看到能走进去却没有碰撞的空壳地图 |

若未来携带受控亡灵进入，入口可有一次门纹响应与骑士侧目；这些表现读取公共事实状态。不在场景里凭“玩家身后有某名字物体”推断剧情选择。

## 4. 建筑和材质风格

延续已有哥特图书馆的尖拱、肋骨线、旧黄铜和石材。深层前庭降低木作与家具比例：图书馆负责保存，前庭负责承压。门框只保留两根主肋和一个尖拱，中心门面大面积完整，能承接战斗剪影。

地面以低对比深灰石为主，可有少量大块切缝，不铺满高频符文。静态供能线细、暗、靠外缘；有伤害的地带宽、明、带倒计时。玩家一眼应能区分环境装饰和攻击。

建议保留三层材质：暗石负责地面与墙的主体，象牙石负责门和关键支撑，旧金负责封印接缝。精细版可以加边缘磨损和接缝灰尘，但先保证玩家眼高与普通画质下材质不泛白、不吞没预警。

## 5. 灯光和声音

主光从玩家左前上方照亮骑士胸、持剑臂和盾面；门后少量冷光勾勒外轮廓；外层供能线保留弱暖色。当前原型只有两盏点光。精细版优先调整范围和烘焙，不通过增加大量实时光源补细节。

二阶段让门的封印缝和骑士胸纹同步变亮，持续过渡，不使用全屏闪白；门后光始终被门遮挡，不拿 Bloom 把角色和预警洗成一团。危险地带显示时适当压住同区域环境光，保证路线可读。

基础声景用低频供能和远处搬运/撤离声音建立压力。三种危险提示采用不同起音：金属双拍对应连斩，单次长蓄音对应突刺，石槽共鸣对应地带；可吞印飞矛是清楚的分次发射声。声音必须匹配实际释放，暂停不继续排队补播。不开声音也能通过动作和图形判断。

## 6. 场景如何配合招式

- **连斩：** 中央没有柱子遮住肩和持剑手；绕到盾侧必须可行，后方不是必死角。
- **突刺：** 可见预警覆盖最多 6.4 米的冲势与剑气；普通起手锁向后至少留一个侧闪方向；靠墙时冲势缩短，并正确给出收招。
- **飞矛：** 头肩后景保持干净，让三次准备与释放可见；墙能阻挡弹体，不能从门后穿出。
- **门扉裁断：** 二阶段三条射线仍存在明显空隙；门饰、地面花纹和阴影不制造假的第四条路线。
- **盾誓：** 骑士与边界保持距离，保证玩家能从两侧绕盾；不得选择在背贴墙时无限举盾。
- **盾击：** 玩家被近距离压迫后仍能后退到安全带；精细版击退必须扫掠且有上限，不把玩家推过围墙。

当前盾击没有新增强制位移。精细版若加 0.6–0.9 米后退，先验证靠墙、腾空、残余速度和暂停，不把击退作为必需反制条件。

## 7. 剧情镜头与战斗收尾

血量阈值先冻结所有战斗，再选择镜头。镜头优先采用玩家当前视角与骑士放低武器的姿态，避免瞬间拉到墙后。需要对话机位时，先对双方候选脚点做地面与胶囊检测；不可达则保留原位，仅转向。

对话中门与外层供能线都在构图内，让“封门会影响外面”持续可见。接受封印时可把视线留给门纹与玩家左掌；协作救援时让骑士从门前让出半步；强夺路线才让玩家主动把武器重新抬起。三种演出是后续规格，当前原型没有制作这些结局镜头。

## 8. 分阶段精细化与验收

| 阶段 | 交付 | 通过后才进入下一步 |
| --- | --- | --- |
| A 空间冻结 | 当前圆台、出生点、门、有效边界 | 两侧绕盾可走；突进不会掉出；所有招式有可达安全区 |
| B 建筑轮廓 | 尖拱门框、外缘肋柱、后景封印深度 | 第一人称保持武器和预警可见；镜头不穿墙 |
| C 叙事物件 | 清单、导流线、修复痕、转移托位 | 物件状态与剧情事实一致，能支持骑士决断理由 |
| D 材质灯光 | 独立材质、控制曝光、二阶段光态 | 两档画质与 720p/1080p 均能辨识危险地带 |
| E 性能与发行 | 合并/LOD、剔除未用大厅、构建资源核对 | 在真实设备测帧时间和高峰实体数，不拿编辑器截图替代 |

几何精细化不改变技能尺度。若必须改半径、门宽或地面高度，要同时重测招式范围、出生点、停战机位、突刺扫掠和返回流程。
