# 更新日志

## 1.0.5 · 战斗动作与行为细化（2026-10-19）

- Boss 改为视野、遮挡和间隔采样感知；选择固定换位目标，收招不再自动转向玩家。
- 地面封印改为三片不规则龟裂，紫红裂光与独立石片抬升，保留完整地面碰撞。
- 激光双臂高举、弹幕挥臂释放、裂地双手托举；新增蓄势、锁线、前倾冲撞与停步收招。
- 格挡持续消耗 7 → 18/秒，命中消耗系数 1.5 → 2.8，吞印启动消耗 8 → 14。
- 双方飞弹加入受转速、总转角、有效时间和捕获角度限制的弱追踪。
- 具体参数、文件与本轮验收见 [战斗细化记录](Docs/BossDesign/CombatPolish20261019.md)。

## 1.0.5 · 激光追踪与典狱长模型细化（2026-10-18）

- 激光发射后缓慢追踪玩家，转速上限 10°/秒；保留预警停顿、实体遮挡、格挡及可躲避性。
- 增加曲面象牙裂面、兜帽包边、分层肩甲、指节、誓约链、层叠刻文书页及禁书装订细节；更新原模型 Prefab 和 OBJ 导出。
- 新增细节按动画部件与材质合并，保持原碰撞和动画引用。
- 提供可直接填写意见的 [Boss 设计评审稿](Docs/BossDesign/WardenDesignReview.md)。

## 1.0.5 · 蓄力激光、Boss 位移与格挡条（2026-10-18）

- 加入 2.2 秒蓄力、末段锁定的金紫激光；光束与伤害受实体遮挡。
- Boss 按玩家距离追近、后撤、绕侧，收招与齐射时继续移动；胶囊扫掠约束碰撞。
- 右键保留吞印并支持持续格挡；左下新增格挡条，包含消耗、延迟恢复和破防，持盾不能同时射击。
- 更新战斗说明、中文字体、激光 Prefab 与专项验收工具；实际验证见 [实现与验证](Docs/BossDesign/ImplementationAndVerification.md)。

## 1.0.5 · 禁书守卫可玩首版（2026-10-18）

- “深入探索”接入独立封印厅，复用当前玩家、输入系统与 Esc 菜单。
- 制作缄默典狱长的可编辑网格、旧金/诡紫材质、冠环/书翼/胸书动作，以及五种攻击表现 Prefab。
- 加入两阶段、三种带预警的攻击、秘文弹、吞印与强化攻击、生命与战斗 HUD。
- 加入胜负、重试、暂停、失焦保护与返回图书馆；新增战斗按键可换绑。
- 新中文烘焙到独立 SDF 字体；修正 UI 隐藏时重置手部 Animator 的警告。
- Play Mode 自动输入已跑通失败 → 重试 → 二阶段胜利 → 返回。详细检查见 [实现与验证](Docs/BossDesign/ImplementationAndVerification.md)。未提交、未推送，未制作独立运行包。

## 1.0.5 · 开发中（整理日期：2026-10-15）

基于 1.0.4 / c3a80b9；开发分支 dev/1.0.5。本条记录当前工作区变化，不表示已创建 Release、标签或完成推送。

### 新增

- 统一 Esc 菜单与棕金风格 UI：探索指南、设置、用户馆藏空状态、功能概述。
- 可操作的画质按钮、鼠标灵敏度滑条、按键换绑及 JSON 保存。
