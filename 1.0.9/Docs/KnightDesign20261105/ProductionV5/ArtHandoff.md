## 角色结构

主体将分件合入蒙皮网格，银甲、暗关节、象牙与织物、旧金和必要发光保持分开的材质槽；第二档细节移除铆钉、小鳍、细刻片等部分。武器、腕盾与待发刃单独处理，以保留必要的显隐和特效挂点。LOD0 约 7,000 三角面，低于提示词的起步预算上限，不为凑面数盲目细分。

实际额外细节包括胸甲连接铆钉、腿甲槽线和面甲眉框；它们不新增碰撞。脚、掌、头、双环和十二条长带均有骨骼或具名挂点。角色仍沿用原始银甲轮廓，尚不等于精细提示词全部美术要求已经达标。

| 挂点 | 约定用途 |
| --- | --- |
| `BladeBase` / `BladeTip` | 实际刃迹采样和特效，不能自行产生额外伤害 |
| `Grip_R` / `Grip_L` | 右手主握与左手可释放辅助握点 |
| `SealEmitter` / `ChestSeal` | 手部施法与胸部阶段纹 |
| `HaloRoot` | 双权限环与附属纹饰 |
| `Foot_L` / `Foot_R` | 两段腿约束的终端骨骼 |
| `FootMark_L` / `FootMark_R` | 地面接触的制作参考 |

Blender 源在原工程内保存，材质纹理打包到 .blend；不依赖队友的外部模型目录。源文件的骨骼名称另带 `unity_path` 属性，便于追踪；当前游戏仍使用 Unity 网格与 Prefab，不将 .blend 自动导入替换为一个未经验证的新 FBX。

## 场地模块与空间

| 模块 | 作用 | 净空与制作约束 |
| --- | --- | --- |
| 14m 圆台与大分缝 | 清楚的战斗地面与尺度 | 复用原平整碰撞；装饰接缝齐平，不增加绊脚边缘 |
| 24 个外缘柱间 | 柱基、三束细肋、柱头与墙面节奏 | 布置在外缘，保留半径 12.5m 的通行检查 |
| 双门扇与三层尖拱 | 北侧承压视觉中心 | 保留原门位与出入口；构件有厚度，主门后不直接展示源石 |
| 高位交叉承重肋 | 顶部结构与纵深 | 远高于常用战斗空间，不作为不可见低顶 |
| 门后双层遮挡 | 暗示更深设施 | 不假装存在可探索通道，不添加新剧情机关 |
| 供能接缝与维修夹具 | 解释封门会影响外层 | 固定纹较暗且稳定，不模仿攻击倒计时 |
| 清单与空转移托位 | 提示外层撤离未完成 | 属于环境叙事，不能成为未约定的必收钥匙 |

坐标按米，局部 Y=0 为地面，+Z 朝封印门。玩家出生(0,0.08,-5)，Boss 出生(0,0,4)，门面在 Z≈13.6；源石不摆入前庭。旧场地碰撞保留，新增细饰不做碎碰撞。

## 材质 灯光与优化

石材复用本工程已有 AgedLimestone 基础色与法线，授权范围沿用原素材来源记录，不添加新的第三方许可声明。V5 自制金属细纹为生成来源，银甲高光降低为较柔和的表现；发光和静态金属分开。

场地实时灯为 3 盏：玩家左前的银甲主光、右侧暖补光和门侧冷轮廓光。低强度三色环境光由场地会话保存与恢复，退出时必须恢复图书馆原值。阶段二只缓慢增强门纹和轮廓光，不做全屏闪白。

运行场地按材质合并静态几何，保留分件制作 Prefab 和 .blend；透明阶段纹单独合批，以便通过属性块控制亮度。角色保留两档实际蒙皮 LOD，武器和腕盾保持独立控制。阴影与透明尾迹成本需在目标设备实测，不从三角面数或离屏截图推断帧率。

当前未执行最终静态光照烘焙。后续烘焙应在装配冻结后生成灯光 UV 与探针，再测低画质和后处理关闭；不要为了单张效果图增加一圈实时阴影灯。

## 继续精修时的顺序

1. 在可编辑源中完善甲片承力、手指、关节余量和 UV，保留已验证骨骼与挂点。
2. 对照八招采样动画调整局部穿插、脚底和双手握持；不能只看正面静帧。
3. 优化长带分段权重、裙甲避让与动作轮廓，再考虑提高几何细节。
4. 细化门、壁龛与承重结构，维持通行面积，复验与现有技能范围的关系。
5. 接最终声音、光照烘焙与实机测量，记录真正在目标设备上的结果。

生成来源、绑定、场景优化与自动化验证已经完成；正式美术品质、真人难度、最终混音和设备性能仍需团队验收，不能把本轮称为全部精细制作结束。
