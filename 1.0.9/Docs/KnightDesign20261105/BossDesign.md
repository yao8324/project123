# 封印圣骑士：世界观、角色与战斗定位

> V1 设计推导保留。用户提供洛希德视频后，造型、武器和运动方向已经改版；当前以 [V2 详细设计](RefinementV2/Design.md) 为准。世界规则与玩家战斗基线继续适用。

## 1. 角色要解决的矛盾

“神圣”指他承担的职责、明确的秩序和愿意付出的代价。现有世界观没有确定神祇、教会信仰和天使种族，本次不额外引入这些设定。圣骑士使用的光来自源石供能、装备附魔和深层封印权限。

他守护的不是一座空殿。门后是支撑外部档案、亡灵收容和核心封印的设施；门外仍有未完成的撤离。他判断已恢复力量的怪物可能让灾难继续向外扩散，准备封闭核心、切断外层供能。玩家知道仍有遗赠和生命依赖这些供能，希望争取时间。

因此，这场战斗要让玩家感到“我必须突破他，但我能理解他为什么站在这里”。他的攻击指向战斗区，主动避开撤离区域；转阶段继续维持后方门的封印。玩家逼出停战机会，不等于必须把他杀死。

正式名先保留**封印圣骑士**，称号可用**终扉守誓者**。称号属于本次提案，个人姓名、年龄、是否为百年前参战者本人均不定死。v0.4 只确认他继承百年前镇压怪物的职责，不能据此推导他已活了一百年。

## 2. 世界规则怎样落到设计里

| 已有规则 | 对本 Boss 的具体约束 |
| --- | --- |
| 源石在深处持续供能 | 战斗场景只展示封印门与导流支路，不把源石摆在普通平台上当可拾取奖励 |
| 记忆与能力遗赠有不同规则 | 吞印吸收的是攻击术式的魔能片段，不解释为剥夺逝者能力或吞噬灵魂 |
| 玩家是接受伊莱恩记忆的怪物 | 战斗发生在身份揭示之后；进入本关前必须已有相关剧情事实 |
| 典狱长先救援再要求收容 | 典狱长的担保来自实际救援成果；圣骑士不能靠一句台词自动信任玩家 |
| v0.4 把最终封印冲突分配给骑士 | 典狱长继续负责监狱与外圈，不复制两个角色都负责“最终切断”的混乱职责 |
| 亡灵仍有意识，也可能危险 | 援军路线须走公共阵营系统；解除控制后仍需隔离与引导 |

原 1.0.6 的“归档编号零”是典狱长技术试炼台词，不能拿来替代正式故事开场。三 Boss 与多结局仍是新增方案；当前短篇通关后挑战的独立范围也继续有效。

## 3. 与现有典狱长的区别

| 项目 | 缄默典狱长 | 封印圣骑士 |
| --- | --- | --- |
| 工作方式 | 收容、封缄、控制异常 | 承压、阻断、守住最后门扉 |
| 剪影 | 悬浮长袍、书页翼、破碎冠环 | 接地重甲、剑盾、稳定的完整光环 |
| 运动 | 悬浮侧移、后闪、禁咒 | 有重心的迈步、蓄势突进、停稳防守 |
| 主色 | 深紫黑、旧金、象牙点缀 | 象牙甲、黑钢关节、旧金结构，少量深紫布料 |
| 对玩家的考验 | 识别法术、追踪与范围 | 资源分配、连斩节拍、锁向侧闪和防守拆解 |
| 破绽 | 施法收招与失衡 | 斩击落空、突刺冲势耗尽、举盾结束和被盾击拆防 |

不为提高难度而取消玩家已有能力。保留正面弹反、近身盾击、侧闪、吞印与普通剑击的价值；没有某个能力也可以通过走位和稳定输出完成挑战。

| 三段轻击 | 30/30/43.5；每击 12；距离 2.8 米 | 短窗口稳定输出；第三击增加失衡 |

| 4 回旋封印 | 68；体力 38；冷却 9 秒；半径 3.3 米 | 在安全侧后方输出；精细版若有多个目标，继续统一伤害 |
| 右键 | 起始 0.22 秒弹反；0.65 秒重启限制；持续举盾 12 体力/秒 | 第一斩、突刺可弹反；盾击不允许弹反但可格挡 |
| 正常格挡 | 命中消耗伤害×1.45；不足部分溢出到生命 | 连斩全挡有明确资源代价，不能无成本长按 |
| 吞印 | 启动 10 体力；窗口 0.65 秒；冷却 2.5 秒；正面约 90°、2 米 | 封印飞矛给出可主动迎接的远程机会 |
| 封印力量 | 吞印每枚 +25，弹反 +20；满值下次命中剑击×1.65 | 有利于突破防守，但不要求玩家攒满才可造成伤害 |
| Shift 突进 | 4.8 米/0.24 秒；20 体力；冷却 0.85 秒 | 处理锁线突刺；普通突进本身没有无敌 |
| 极限闪避 | 起步后 0.22 秒真实近失；至少离开 0.6 米；一闪一次 | 新招命中入口必须向原有系统提交实际威胁，不凭按键发奖励 |
| 时停奖励 | 0.75 秒，前 0.45 秒世界 5% 速度；起始 0.30 秒保护 | Boss 动作、预警、弹体使用战斗时钟，不能绕过减速继续伤害 |

盾击拆防前至少要有 24 体力，若先启动吞印再举盾则还会消耗 10。首次教学不能把“右键”粗略说成没有代价的万能防御。守门盾誓提示“盾击”指数字 2 的装备技能，应从实际绑定显示，不假设任意右键都能拆防。

## 5. 外形设计：极简也能说清楚

模型的第一识别层是宽肩、窄腰、接地双腿，右手长剑，左手门扇形盾。第二识别层是面甲的水平观察缝、胸前封印竖线与头后完整冠环。没有大羽翼，避免与典狱长的书页翼抢同一轮廓。

盾像一块能移动的门：平整主面、厚实边缘、正中的合缝纹。举盾时它确实挡在胸腹前，收招时明确移向侧面。剑像把封印结构切开与重新对齐的工具：直刃、旧金护手、窄长的附魔槽。剑气只在挥动时补足距离，不在闲置时一直亮成大块光柱。

象牙甲面表现承担职责的完整性，黑钢关节承载重心，旧金放在结构边和权限纹，深紫只放内衬。建议精细版面积约为象牙 45%、黑钢 30%、旧金 15%、布料与发光 10%；这是美术起点，不是必须精确统计的材质指标。

二阶段不是堕落成黑色怪物。完整冠环出现一次有控制的错位，胸前导流纹转亮，盾边打开少量泄压缝，右膝和肩部留下交锋磨损。他在透支供能和装备，同时仍然守住门。这比突然长出第二套肢体更符合职责，也降低后续建模成本。

## 6. 精细模型与动画制作规格

| 项目 | 建议规格与理由 |
| --- | --- |
| 身高 | 脚底到盔顶约 3.2 米，冠环约 3.65 米；接近玩家仍可在常规视野读取肩、盾、武器 |
| 宽度 | 肩甲约 2 米；盾约 0.9×1.3 米；运动时为武器预留净空 |
| 网格 | LOD0 约 20k–35k 三角面，LOD1 10k–18k；先做轮廓与动作再加纹样；实际性能决定预算 |
| 材质 | 象牙金属、黑钢、旧金、布料、发光遮罩 4–5 槽；不为每片甲单独做材质 |
| 骨架 | 根、骨盆、脊柱、胸、颈头、双臂手、双腿脚、少量裙甲；盾剑为挂点，冠环独立 |
| 必须动作 | 站立/警戒、前后侧步、左右斩与第三下劈、突刺蓄势/冲势/刹停、举剑放矛、地面裁断、举盾/盾反制、失衡、转阶段、停战、失败 |
| 动画衔接 | 动作末尾保留脚步和重心；以完整权重混合，取消动作时不瞬间回 T Pose；伤害不依赖动画事件 |
| Root Motion | 原型关闭；精细版位移也由战斗层胶囊扫掠决定，动画只对齐动作进度 |
| 挂点 | SwordGrip、ShieldGrip、BladeBase、BladeTip、SealEmitter、ChestSeal、HaloRoot、LeftFoot、RightFoot |
| 碰撞 | 躯干胶囊；武器/甲片不作为阻挡玩家的碎碰撞；伤害范围由技能几何决定 |

精细化顺序：握持和脚底落地 → 前摇剪影 → 命中时刻姿态 → 收招重心 → 混合 → 冠环与布料次级动作 → 纹样。不能先堆雕花，最后才发现突刺握不住剑或盾挡住整张画面。

## 7. 剧情位置和台词提案

入场不是立即宣判玩家邪恶。圣骑士先要求停步，并报出他已经观察到的封印异常与供能风险。准备区应先让玩家看见还在撤离的迹象和已经尝试过的修复措施，再理解双方为什么不能各自等下去。

- 入场候选：“源石不能离位。外层封闭前，退回门后。”
- 玩家候选：“门外还有人。那些记录还靠这条回路活着。”
- 骑士候选：“我已送出两次撤离令。再一次失稳，裂隙会越过外环。”
- 转阶段候选：“我守的门后，也有不能失去的人。”
- 停战候选：“你已经能破坏它。现在，告诉我你要保住什么。”

“两次撤离令”是精细版待制作的具体证据提案，必须在现场清单或前置剧情体现，不能只靠一句无法核对的台词替角色开脱。正式采用前由剧情负责人统一文本与称谓。

剧情阈值暂建议 20%，二阶段阈值暂建议 55%。最终选择仍按 v0.4 的事实条件开放 `cooperate_rescue`、`accept_seal`、`dominate_core`。Boss 只请求 `knight.final_decision`；公共系统判定资格、提交选择并决定继续/停战/收尾。当前原型只保留冻结与请求，不实现三结局、不发放跨关奖励。
