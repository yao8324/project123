# R16 骑士整体盔甲形体修订

本轮依据 `SanctuaryBlueprint56m20261107/images/07_winged_knight_master.png`，对照当前模型与 Unity 招式截图进行整体修改。R15 下载包保持原样，本文件记录后续模型迭代。

## 已修改的形体

- 肩甲：三层肩片、前侧弧形甲和全部金边一起收紧，静止网格总宽由 1.05037 米改为 0.93710 米，厚度方向与竖向展开同时收拢。
- 胸腹：前胸甲最大宽度由 0.58059 米改为 0.54576 米，增强胸部前凸和中脊过渡；以贴合真实甲面采样的细金线、叶片取代旧粗纹饰，纹饰合为一个蒙皮网格。
- 上臂：甲袖及暗色内衬沿现有上臂骨骼方向搭建，连接肩甲和肘甲。修正了旧直立内衬突出在肩甲外侧的问题。
- 护膝与护胫：收小护膝，收紧脚踝、保留小腿腹部弧度，并让对应金边同步变形；护胫下沿略向脚背延伸。

尺寸数据是静止网格边界，不表示最终视觉验收。模型保留 72 根骨骼、38 根羽片骨、12 根布料骨以及走动/冲刺/跳劈三段动作，蒙皮网格从 380 个减至 360 个。

## 当前验证

Blender 原生与 FBX 回读的骨骼、网格和动作结构检查通过。羽片与所选头部/胸背/肩甲/上臂表面在每段动作 13 个采样姿态中记录为 0/0/0 相交。

120Hz 布料与腿甲表面采样：慢行 0、冲刺 4、跳劈 0 条交叠记录；冲刺残余穿插尚未消除。该检查不覆盖所有物体，不证明连续运动完全无穿插。

Unity 导入和受控战斗复测结果另记在 Progress.md 与 CombatRuntimeCheck_R16.txt，尚未据此声明新的 Mac 构建或全程人工通关。
