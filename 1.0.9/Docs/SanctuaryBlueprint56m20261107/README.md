# R3 · 56 m 终扉圣堂与黄金翼圣骑士

本包是**建模设计交接**。包含 30 页整合 PDF、8 张原图/概念图（含 1 张废止历史版）、9 张矢量尺寸图与 PNG 预览、统一尺寸与材质数据、57 个模块/道具实例、管线路径、黄金翼开合骨架数据、动作参数和逐部件验收表。

## 打开方式

- 人阅读：先打开 `终扉圣堂_黄金翼圣骑士_56m_完整建模交接.pdf`。
- 给模型：把整个 ZIP 和 `START_HERE_FOR_MODEL.md` 一起提供，要求先读 `BUILD_BRIEF.md`。
- 精确搭建：以 `data/` 数值和 `drawings/*.svg` 为尺寸依据，不能从透视概念图量取比例。

## 版本和状态

- 原 28 m 战斗直径扩大至 56 m；大厅新定净空 64 × 72 × 36 m。
- 主体角色 2.28 m（盔顶）；实体黄金翼展 5.80 m；收拢宽 1.65 m、深 0.85 m。
- 本包未更改现有 Unity 小场地、Boss 移动逻辑或动画，也不包含新的角色网格。下游必须实际制作并运行验收。
- 图片采用内置 image_gen；提示词存于 `source/image_prompts.json`。建筑详图为设计补全，原图局部放大保持原内容。
- 武器生成被工具拒绝，改为 D07 精确矢量设计；动作插画有少量装备省略，强制补正规则在规范第 12 节。

## 验收口径

每个建筑模块、道具、角色部件、材质、照明和动作都必须独立 ≥90/100，并通过尺寸、数量、净空、穿插与动画播放硬条件。`acceptance_scorecard.csv` 的 39 项均保留为 NOT_EVALUATED，等待实际模型及证据，不能把本包视为已经完成模型验收。

## 文件说明

`source/make_package.py` 是图纸和文档再生成工具，使用 Python、NumPy、Pillow、ReportLab、PyMuPDF；本机使用 Arial Unicode 字体路径。它不是场景或模型生成器。`source/image_prompts.json` 记录生成来源。QA 缩略图与中间 PDF 未放入正式 ZIP，以避免模型把它们当成额外参考版本。
