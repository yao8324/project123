# 可直接交给建模模型的任务

按此包完成“终扉圣堂与黄金翼圣骑士 R3”的可编辑 3D 资产、场景及动画。不要把输出限制为图片或文字计划。

## 先读什么

1. `BUILD_BRIEF.md`：完整执行规范，所有章节均有效。
2. `data/dimensions.json`：统一单位和尺寸；`drawings/D01-D09`：精确尺寸与控制点图。
3. `data/module_placements.csv`、`data/pipe_paths.json`：场景模块和管线位置。
4. `data/materials.csv`：12 类材质基准。
5. `data/wing_rig.json`、`data/animation_states.csv`：骨长、关节位置、局部旋转与动作时间。
6. `images/`：用最终外观图片完成复杂曲面、金边和雕花，先读 `data/image_manifest.json` 的版本状态。

## 哪些图有效

- 原始气氛、建筑与叙事：`00_reference.png`。
- 建筑细节：`01_architecture_details.png`；外围道具：`03_evacuation_props.png`。
- 最终人物：`07_winged_knight_master.png`；翼根/甲片：`08_wings_armor_detail.png`。
- 慢走/冲刺：`09_walk_dash_storyboard.png`；跳跃攻击：`10_jump_attack_storyboard.png`。
- `04_knight_turnaround.png` 是无翼废止版，仅用于历史记录，不执行其宽肩披风。
- 武器形状与尺寸执行 `D07_weapons.svg`；所有动作全程持右剑左盾，不能因分镜省略而丢失武器。

## 不可改变的核心条件

- 1 单位 = 1 m；大厅净宽 64、净长 72、冠顶 36；中央圆直径 56 m，全部地面保持开阔。
- 12 座束柱、6 道主横拱、5 个中央拱顶跨；柱头与门环有真实金属厚度；大理石纹脉不是凸起线条。
- 装甲盔顶 2.28 m；黄金实体双翼展开宽 5.80 m，收拢宽 1.65 m；每侧 19 枚主羽。
- 慢走收翼；冲刺 0.95 s / 位移 8 m，羽翼展开后掠；跳攻 1.60 s / 位移 10 m / 脚底最高 4 m，落地后回收。
- 角色、武器和人用道具不随场地放大。衣摆、翼片、盔甲、手、剑盾和背饰在动态中不得互穿。
- 不得给模型整体缩放来“差不多对齐”；必须使用精确尺寸与固定骨长。生成概念图的像素比例不替代数据。

## 制作顺序

尺寸白模与人体标尺 → 净空/比例验证 → 建筑主次结构 → 真实开口与厚度 → 材质与细部 → 人物/剑盾 → 黄金翼骨架 → A01/A02/A03 动作 → Unity 组装与实际播放 → 逐项验收。

若绑定发生问题，先查轴向、固定骨长、局部四元数和收展顺序，不能缩短羽片或把翼根搬到头盔上。若图像与数值冲突，数值决定尺度；图像决定装饰语言。执行前把所有无法解开的冲突列出，不能自行忽略要求。

## 交付与验收

交付原生可编辑模型、交换模型、PBR 纹理、骨架、三套动作、场景、碰撞代理、LOD、固定相机图片与动画视频，以及填写完整的 `acceptance_scorecard.csv`。

按 `acceptance_rubrics.json` 逐项评分：每一行独立 ≥90/100，硬性条件全部通过；不允许取平均数。未运行或未检查的项目填 NOT_EVALUATED，不得填“通过”。每个分数附证据路径与扣分理由。达标后再宣布完成。

本包提供设计和验收标准，并没有预先证明你将生成的模型满足 90 分。不得把设计包内 `design_validation.json` 的数值一致性检查冒充最终模型验收。
