# IM MONSTER 我是怪物比赛版完整制作策划

版本 v0.3　更新日期 2026年11月3日　最终提交 2026年11月7日22时前

本版将已有图书馆、维护厅、第一人称交互与故事框架组织成能够独立通关的单人短篇游戏。玩家从封忆师的工作记忆中醒来，先发现自己不是伊莱恩，再确认自己就是被封印的怪物，最后主动约束力量、抢救档案，以一次完成的救援结束游戏。比赛主题“我是怪物”必须在正常通关中得到明确回应。

本版是用户要求补全的比赛制作方案。既定世界规则和已有资产继续沿用；新台词、身份确认方式、最后的救援玩法和短篇结尾属于本版新增设计，不记为已经实现或团队已验收。Client按团队流程收取、安排分工与整合；本文件不改写其他成员的当前任务，也不代表新功能已进入main。

## 一 比赛规则与交付范围

比赛活动书要求11月7日22时前交最终作品及材料，11月13日22时前评委体验与答辩，11月14日试玩和投票。日期以用户提供的活动书为依据；具体提交入口与最终获批通知由负责人核实。“我是怪物”为用户明确提供的主题，活动书正文没有列出固定命题。

| 规则 | 本版对应交付 |
| --- | --- |
| 可玩的原创作品与创新说明 | Windows单人短篇，正常入口可完成全部主线；说明记忆误认、身份发现及克制力量的互动 |
| 作品介绍与成员分工 | 中文简介、完整分工及既有项目与新增内容对照；真实姓名由负责人填写 |
| 规则或操作说明 | 键鼠操作、目标、检查点、重试、退出及战斗挑战的独立范围 |
| 可试玩版本及设备要求 | Windows 64位离线候选包、版本标识、实测设备与已知问题 |
| 1至3分钟演示视频 | 建议2分钟，展示操作、关键玩法和完成画面；不能用视频代替可玩主线 |
| 素材来源说明 | 模型、贴图、字体、声音、插件的来源与许可核查；第三方和AI辅助范围逐项说明 |

评委评分中游戏性30分、创意20分、完成度20分、玩家体验20分、展示表达10分。综合成绩为评委评分70%加玩家投票分30%。制作优先顺序是让玩家理解目标、亲手完成关键行为、获得清楚反馈，然后再增加表演精度。

交付定位是完整短篇，不把原长篇世界观所有事件塞入本次比赛。首次游玩暂以8至12分钟为设计目标，必须用首次试玩实测调整；允许熟练玩家更快通关，不延长字幕或等待来凑时长。评审统一体验时长尚未给出，另准备3分钟讲解路线和2分钟视频。

P0必须完成：主菜单、完整故事、三份档案、维护节点、两次身份发现、最后救援、结尾、暂停和检查点、操作说明、离线运行包及参赛材料。P1在主线完成后做：配音、更多近景动作、现有Boss的独立挑战入口。P2留到赛后：完整监狱、新NPC战斗、亡灵大军、源石大招及原长篇最终决战。

## 二 故事规则与比赛版改编

终境守藏院依靠源石供能，保存逝者自愿交出的记忆与指定遗赠的能力印记。源石仍在深处，遭袭的是供能和封印设施。维护厅是局部导流设施，不是怪物核心封印室。修好三处节点只恢复这片区域，不能宣布灾难已经解决。

伊莱恩维尔是开场记忆的原主。玩家先操作她整理档案，袭击后通过第一人称连续黑屏切换至失忆的人形怪物。记忆中的工作经验解释玩家为何熟悉档案；它不自动授予所有死者的魔法。醒来后，字幕、任务、HUD和人物称呼都不能确认玩家仍是伊莱恩。

典狱长在本篇组织撤离、保护记忆并向幸存者求助。救助不是复活，称呼不带伊莱恩姓名。他在本篇不与玩家敌对。已有Boss战若保留，放在通关后独立的“战斗挑战 非剧情演示”，进入前解释其不属于本篇故事，结果不改写本篇结局。

比赛版新增压缩方案：返回时通过蓝绳、工作牌和腹部伤口确认“我不是伊莱恩”；随后通过伊莱恩尚未归档的事故记录、玩家自身的封印共鸣和一段原有记忆闪回确认“我是怪物”。这两次揭示必须分开，先推翻误认，再给出可靠证据。怪物身份不提前写进任务栏。

事故记录只是一份本地封印监测抄件与伊莱恩的临终记录，不是无所不知的身份系统。新增设定为古老封印在逃离者左掌留下三道缺口环纹，能与事故抄件中的共鸣纹对照。环纹来自怪物自身原有封印，最后使用的也是自身正在恢复的一小部分力量，不是阅读档案获得能力。此视觉设定在本版定下制作形式，不能解释为源石已被玩家拿走。

本篇结局闭合救援目标：玩家承认自己的身份，将力量限制在小范围内，保护尚存的遗赠，并把本批档案送进原馆内的安全转移箱。典狱长继续疏散，暂未知道主角身份。原长篇后续的追捕、恢复全部力量及最终决战继续保留，不用“未完待续”替代这次任务的完成反馈。

## 三 玩家体验与关卡路线

游戏以第一人称探索、物件查验和短时力量控制为主。核心循环是看懂现场线索、完成一次明确交互、看到环境变化，再决定下一步。没有战斗经验的玩家应能完成故事；玩家对力量的主动约束承担比赛主题表达。

路线为工作台、侧门、维护厅三个外圈节点、同一工作台、遇难者证据、失稳回路、安全转移箱。只用现有图书馆和维护厅两处空间。最后的回路和转移箱放在工作区附近，复用现有道具形制，不扩建第三张地图。

| 阶段 | 玩家做什么 | 清楚的完成反馈 |
| --- | --- | --- |
| 档案工作 | 查验三份遗赠记录并系蓝绳，提交本批核验 | 三份标记核验完成，封档绳结出现，交接提示生效 |
| 突袭与醒来 | 经历短促受袭，听见救援，重新控制角色 | 黑屏结束，同一桌面已受损，目标改为稳定供能 |
| 维护供能 | 从侧门到三个节点，按指引依次稳定 | 节点由青蓝改为稳定青绿，数量从0到3，返回提示出现 |
| 返回取证 | 找到记录，在遇难者身上核对三项证据 | 三项观察确认，出现“我不是伊莱恩” |
| 确认身份 | 阅读事故抄件，观察左掌共鸣并触发闪回 | 两类证据对应，出现“我是怪物” |
| 约束力量 | 引导三段短脉冲，保护封存结构 | 失稳声减弱，裂隙收束，档案可安全转移 |
| 完成救援 | 取走本批遗赠并放进转移箱 | 箱体封印闭合，救援目标完成，结尾与制作名单 |

引导优先使用原有灯光、工作台构图、节点编号和短字幕。目标栏一次只显示当前目标；物件靠近时才显示当前绑定的交互键。20秒没有进展时补一条位置提示，玩家移动或完成动作后停止提醒；不让屏幕持续堆满箭头。

## 四 开场与维护的逐场脚本

### 档案工作

开始新游戏后在已验证工作脚点附近进入可控状态，画面标题为“终境守藏院 记忆档案馆”。第一次内心字幕为“最后一批，核对完就能交接了。”工作牌在灾前可见伊莱恩姓名，查工作牌是可选观察，不能成为隐藏的通关条件。

目标为“查验三份遗赠记录”。三份记录可任意顺序打开，正文可滚动；打开不算完成，玩家按面板中的“核验完成”才设置对应标记。关闭或暂停不会误计。已读记录可以重读，不重复累计；不设置强制阅读秒数。

系绳可以先于或后于阅读。三份核验和系绳都完成后，三号档案原有面板出现“完成本批交接”。玩家确认并关闭面板，才进入袭击。这样玩家有准备时间，袭击不会在阅读中途抢走操作权。内心字幕为“自愿交付，逐项核验。都齐了。”

### 突袭

远处传来警报、石块震动和物件坠落，既有灯具短暂变暗。字幕为“警报声从地下传来。”随后侧后方短促撞击，视角下沉、腹部衣料撕裂声、记忆载体落地声，进入黑屏。攻击者不制作完整队伍，也不显示来历不明的人物脸部。

这一段总演出建议12至18秒。伊莱恩听见警报时抱起刚系好的三号档案包护在腹前，使用一次手部局部或抱起声即可；袭击后同一封档包留在遇难者怀中，返回时绳结才成为证据。关闭强闪烁模式下用一次渐暗代替频闪，不晃动镜头。袭击开始后冻结移动与物件交互，Esc仍能暂停；不得让重力单独继续。中途重试回到开场检查点，不能留下半受损的桌面或重复声音。

伊莱恩在生命最后阶段启动紧急交付，载体尚未来得及进入正常保管状态即发生失控。本次用声音和短近景表达，不需要死亡角色全身动作。黑屏完成后才切换到玩家现在的身体；不出现“复活”或确认新身体身份的字幕。

### 醒来

从同一工作区低视角渐亮，受袭后散页、错位档案和翻面工作牌可见。画外典狱长说：“听得见吗？先别站起来。”短停顿后说：“还能行动就帮我一件事。侧门下面有三个维护节点，先稳住它们，上面的记忆撑不了太久。”

玩家内心：“这里……我知道怎么走。”镜头站起后完整归还移动、视角和交互；目标为“从侧门进入维护厅”。不在任务栏显示姓名、怪物、收容编号或死者身份。醒来检查点保存于玩家安全站起后，不能在镜头压低时记录玩家脚点。

典狱长只以画外声音和门外暖金光响应存在，无需新增完整同行AI。字幕是必需品，真人配音为可选。若醒来演出重试或跳过，必须重放最终状态和当前目标，声音可以跳过，剧情标记不能缺失。

### 维护供能

玩家对侧门按交互键，短淡出后出现在维护厅入口内侧，面对中央。画外提示：“沿外圈走，先看一号。别碰中央的封印纹。”中央不增加战斗、不生成敌对典狱长，三个节点沿用已交付模块。

节点顺序为一号、二号、三号，目标同步显示“稳定节点 0/3”等。每个节点第一次有效交互后播放约1秒局部收束，稳定后拒绝重复推进。提前碰后续节点只显示“先稳定前一个节点”，不扣进度、不锁死。所有标记由程序状态保存，不能只看材质判断完成。

一号完成提示“导流恢复”；二号完成提示“档案供能恢复”；三号完成提示“局部回路稳定”。画外典狱长：“这一段稳住了。回去把尚未转移的记录带出来，我在疏散口接应。”目标改为返回工作区，厅内出口保持可辨认。此处没有倒计时，不用玩家失败来制造灾难严重程度。

## 五 身份揭示与完整结尾

### 返回与第一次身份发现

玩家从厅内出口回到原侧门安全脚点，同一桌面的封档状态和受袭状态保持。取回记录时，桌后传来轻微载体响动，目标为“查看桌后”。遇难者位于同一工作区的近处，可由遮挡和近景限制视野；具体位置必须先在正式场景核对碰撞与取景，不能把未验证坐标当安全站位。

首选资产为静态覆布人形，只显示袖口、工作牌和腹部受伤的衣料局部；无需完整脸部、行走骨骼或血腥细节。不复用典狱长角色冒充伊莱恩。三项证据分别可观察：怀中同一档案包上开场亲手系的蓝绳结、印有伊莱恩维尔姓名的工作牌、与袭击衣料撕裂位置对应的腹部伤口。

观察提示依次可为“这个绳结，是我系的。”“伊莱恩维尔……名字在她身上。”“受伤的是她。”三项观察可任意顺序完成，每项只记一次。全部完成后内心字幕为：“那些记忆属于她。我不是伊莱恩。”这时仍然不直接告诉玩家是怪物。

若11月5日中午仍没有合格的覆布模型，用同一地点触发的三张固定近景图承载袖口、工作牌、伤口观察，保留玩家逐项确认和完整台词。图像须来自有权使用的资产并在素材表注明；不删掉这一层身份推理，也不把任意尸体静帧当作已完成3D角色。

### 确认我是怪物

遇难者旁的未归档载体提供事故记录，正文见文案章节。读完后允许玩家抬起左掌观察，三道缺口环纹产生与抄件一致的共鸣。一个不超过6秒的闪回呈现封印内向外看的视角、同一环纹和第一人称挣脱声；画面用已有维护厅素材制作抽象片段，不把维护厅空间说成核心封印现场。

事故记录给出可核对事实，身体共鸣提供当前证据，闪回补上主角自己的认识。玩家内心：“封印里的东西，是我。……我是怪物。”任务随后为“稳住失控的力量”。第一次身份发现后的三条证据标记和阅读完成标记都满足，才允许播放；重读不重复闪回。

画面呈现由暖金变为受控的深蓝黑雾，只限左掌和近处回路。此时可以第一次在面向玩家的文本中明确“怪物”。不显示大军、变身全身模型、源石离位或典狱长翻脸。

### 最后的救援玩法

力量共鸣使工作区附近原本受损的回路再次失稳，封存结构开始松动。典狱长画外：“那边还有没转走的遗赠。能听见的话，把它们带出来！”玩家内心：“我能压住它。慢一点。”玩家需要引导自身力量完成三次短脉冲，随后才能拿起本批记录。

操作使用当前交互键，默认按住E引导、松开E收束。界面在此首次显示“引导强度”及明确的安全区，不沿用战斗“怪物力量”HUD。开始先给一次无惩罚的教学脉冲，再完成三段有效进度。按住时强度上升，松开时下降；处于安全区才增加封存进度。每段达到进度后自动收束，松开按键后才能开始下一段，防止长按一口气跳过。

建议初值：强度0至100，安全区35至70；按住每秒增加30，松开每秒下降25；安全区累计1.2秒完成一段，三段完成。在安全区外暂停累计但不扣已积累进度，只有过强会重置当前段。超过85持续0.5秒会回响过强，当前未完成段归零、自动降到20并提示“先松开，让回响减弱”，已完成段保留。此数值为待试玩调整的设计值，没有运行验证，不承诺手感已经成立。

失败只重试当前段，不导致死亡、不销毁档案。已完成段和身份进度保留；连续失败三次显示“辅助引导”，可扩大安全区至20至85并放慢强度变化。开启后照常完成故事。离开交互范围、打开菜单或失焦时立即暂停进度并清掉长按，返回后须松开再按。全程允许关闭镜头晃动与强闪烁。

这一段表达怪物的力量有危险，玩家可以选择约束它。过程不给杀人奖励，不增加本篇敌人。需要的程序内容是一套小范围交互状态与反馈，不借此扩写新的战斗系统。

### 结尾

救援完成后玩家取走这批记录，目标改为“将遗赠放入转移箱”。箱体位于工作区通往侧门的已知方向，复用档案匣外形，区别于普通摆设。玩家放入后箱体封印闭合，淡出的警报被远处撤离声取代。典狱长：“收到了。这里还有人活着，继续往出口走。”

内心最后一句：“我记起了自己。留下这些人的记忆，是我自己的决定。”画面显示“本批遗赠已安全转移”，随后为“我是怪物”。结尾交代这次救援已经完成，守藏院仍有人正在撤离；不宣告世界获救，也不虚构原大纲最终胜负。

结束页提供“重新开始”“返回主菜单”“退出游戏”；独立挑战只有经过验收才显示。完成标记在安全保存后再显示结束页。没有隐藏物件或额外阅读阻止正常结尾；制作名单和素材鸣谢可返回查看。

## 六 操作状态与检查点

默认操作沿用现有工程：WASD移动、鼠标视角、Shift冲刺、Space跳跃、C蹲下、E交互、Esc暂停。提示读取实际绑定，不能只写死E。剧情中的左键用于界面确认，右键和战斗攻击在故事模式不生成弹体；独立挑战重新启用原战斗输入。最后救援只在有效目标范围内接管交互动作，不启动第二套输入器。

阅读时显示鼠标，冻结移动和视角；关闭面板后等待交互键释放再恢复。过场中冻结角色运动和游戏进度，Esc可暂停；窗口失焦等同暂停。暂停恢复不补算长帧，不保留按住状态，所有危险、声音播放点和力量进度使用一致的暂停语义。

采用四个自动检查点：新游戏开始；醒来站稳；返回工作区；身份确认后最后救援开始。检查点包含阶段、三份档案核验、系绳、三个节点、三证据、身份确认和已完成救援段。保存到游戏用户数据目录的独立比赛版存档，带格式版本，写入临时文件后替换；不写进仓库Assets或源工程。程序负责具体实现。

主菜单“继续游戏”只在有效检查点存在时显示。损坏或不兼容的检查点不崩溃，提示“此记录无法继续，请开始新游戏”；开始新游戏确认后重置本次故事。暂停菜单可回最近检查点，进入前确认会丢失该点之后的未保存进度。完成通关保留完成记录，重开故事不沿用旧节点计数。

故事模式正常路线不设置死亡。跌出场景立即回到最近已验证安全位置；力控失败重试当前段；过渡失败保留原区域和旧检查点并恢复输入。返回或重试后只保留一个玩家、一个当前区域实例和一套UI。持续按键、重复点击、退出阅读和过渡撞在同一帧，都只能推进一次。

## 八 三份档案与关键文本

下列档案正文为本版新写的剧情候选，各120至180中文字。程序按槽位绑定，不拿原演示书籍替代。三份记录用于建立世界规则，不要求玩家记住专有名词才能通关。

### 一号档案 百年前的守夜记录

封印落成后的第七夜，守夜人仍能听见岩层深处的震动。百年前的战事已经结束，那头企图夺取源石的怪物没有死去。我们将它留在世界尽头，让源石持续维持镇压。后来，导流设施把逸散的魔能引向地表，守藏院才有了长明的灯。请后来者记住，这里的光依赖一份尚未结束的看守。维护记录不得因年代久远而省略。

核验摘要：“古老封印仍在持续运转。”此处没有证据确认当前玩家身份。

### 二号档案 自愿遗赠的登记

我愿把修桥时的见闻和这封写给女儿的信留在这里。她可以来读，也可以选择不读。至于我生前用于测量的术式，只交给登记在册的继承人；其他能力随我一同消逝。请封忆师逐项核对我的意愿，不要把记忆当作供人取用的力量。等这份交付完成，我就能安心离开。若供能中断，请先保护已经封存的内容，不要擅自重新开启。

核验摘要：“记忆与能力的遗赠都要尊重本人意愿。”

### 三号档案 供能巡检便笺

今天更换了第三路回路的连接片。档案中的记忆并非封好便能永存，维持结构的魔能一旦不足，声音会先断续，随后连熟悉的面孔也会变得模糊。发现灯纹失稳时，应先恢复局部导流，再检查档案供能，最后锁定稳定回路。不要为了抢亮一盏灯耗尽整段余量。每一份看似安静的遗赠，都有人在另一端等着把它带回家。

核验摘要：“维护顺序为导流、档案供能、稳定回路。”

### 事故抄件与临终记录

封印监测抄件：“核心封印异常开启，受封对象离位。外逸共鸣呈三缺环纹，残留于掌部。此页只转抄当次读数，不能用于确认其他幸存者身份。”临终记录：“来不及归档了。我自愿留下这段记忆。若有人接到它，请先救那些还没被带走的遗赠。”

该文本为比赛版新增剧情道具。必须与随后主角掌纹、闪回共同成立，不能只靠一张纸让玩家接受身份变化。原未定的长期记忆融合与全部能力恢复没有被这条抄件提前解决。

### 面向玩家的界面文字

主菜单为开始游戏、继续游戏、操作说明、设置、制作与素材鸣谢、退出。暂停页为继续、操作说明、回到检查点、设置、返回主菜单。故事目标只写具体行动，如“核验遗赠记录”“从侧门进入维护厅”“稳定节点 1/3”“查看桌后”“对照事故记录”“引导力量保护遗赠”“将遗赠放入转移箱”。

醒来后到确认身份前，禁用面向玩家的旧文案“怪物力量”“收容物编号零”“它认出了你”及“伊莱恩继续前进”。该阶段提示称呼为你、幸存者或不称呼。标题可以使用比赛主题，但进入故事后不借HUD替玩家揭底。
